The PNG files in this directory were created specifically for QuisquisLingo
with OpenAI ImageGen through Codex on 2026-09-02. No third-party source artwork

Each production icon is a 256 × 256 px, transparent, non-interlaced RGBA PNG.
The generated source was normalized to a four-color solid palette for the
flat, no-gradient Lesson-icon standard.
