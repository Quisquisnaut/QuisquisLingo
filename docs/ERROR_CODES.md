# Error codes

Version 0.1.3

COURSE-001
Course file missing.

COURSE-002
Invalid or unreadable course data.

COURSE-003
Unsupported exercise type.

TTS-001
TTS engine unavailable.

TTS-002
Requested voice/language unavailable.

TTS-003
TTS synthesis failed.

TTS-004
TTS cache write failed.

DATA-001
Local storage read/write failure.

DATA-002
Progress data invalid or corrupted.

APP-001
Unexpected internal error.

## Logging policy

- Logs stay on the device.
- No automatic upload.
- User-facing errors show a short message and error code.
- Technical details are written to the local diagnostic log.
