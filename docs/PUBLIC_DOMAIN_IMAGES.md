# Public-domain images

The former `olive_tree.png` startup artwork was retired and removed in QQL
234. It came from the *Olea europaea* plate in *The North American Sylva*
(1819), François André Michaux et al., via Wikimedia Commons, Public Domain /
Public Domain Mark:
https://commons.wikimedia.org/wiki/File:NAS-087_Olea_europaea.png

This historical source note is retained even though the image is no longer
distributed. Current World Flag provenance and licenses are documented in
`assets/world_flags/manifest.json` and the adjacent license notices.
