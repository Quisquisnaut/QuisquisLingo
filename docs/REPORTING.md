# Reporting bugs and course errors

QuisquisLingo 0.3.2 includes a report flag to the top-right corner of every normal exercise screen and Language Duel exercise.

Tap the flag and choose **Course error** for a wrong answer, typo, translation, audio, instruction, or other course-content problem. Choose **App bug** when the app does not work, display, or respond as expected.

The app does not send anything. It copies a ready-to-paste report to the system clipboard. The report contains a placeholder for the learner's description followed by the technical context needed to find the exact item: app version, platform, course and course version, chapter, topic, round, exercise ID and position, exercise type, visible exercise text, and current answer state.

After copying, paste the report into whatever feedback channel is being used. No account or network connection is required.
