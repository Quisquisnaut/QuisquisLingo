QuisquisLingo - Windows मार्गदर्शिका
=================================

QuisquisLingo भाषा सीखने वालों और पाठ्यक्रम बनाने वालों के लिए एक भाषा-अधिगम
एप्लिकेशन है। इसमें व्यवस्थित पाठ, इंटरैक्टिव अभ्यास, ऑडियो गतिविधियाँ और
पुनरावलोकन के साधन शामिल हैं। साथ ही, यह भाषा पाठ्यक्रम बनाने और संपादित करने
के साधन भी प्रदान करता है।

इसे भाषा सीखने के इच्छुक लोगों के साथ-साथ अपने पाठ्यक्रम बनाने वाले लेखकों,
शिक्षकों और अन्य उपयोगकर्ताओं के लिए भी तैयार किया गया है।

QuisquisLingo कैसे काम करता है, इसका संक्षिप्त दृश्य परिचय देखने के लिए पैकेज
में शामिल QQL infographic.png देखें।

QuisquisLingo शुरू करने के लिए QuisquisLingo.exe चलाएँ।

पैकेज का उपयोग
---------------

इस पैकेज में QQL एप्लिकेशन शामिल है। इसे शुरू करने से पहले पूरी ZIP फ़ाइल
निकालें और दिए गए सभी फ़ाइलों तथा data फ़ोल्डर को एक साथ रखें। अलग-अलग EXE या
DLL फ़ाइलों को वितरित, स्थानांतरित, हटाएँ या उनका नाम न बदलें।

आरंभिक जाँच
------------

शुरू होने से पहले QuisquisLingo आवश्यक पैकेज फ़ाइलों, Windows अनुकूलता और
Media Foundation की जाँच करता है। ये जाँच कभी भी सॉफ़्टवेयर डाउनलोड या इंस्टॉल
नहीं करतीं, व्यवस्थापक अनुमति नहीं माँगतीं, रजिस्ट्री नहीं बदलतीं और Windows में
कोई परिवर्तन नहीं करतीं।

जिस समस्या के बावजूद आगे बढ़ना संभव हो, उसके लिए Continue anyway और Cancel
वाला एक संदेश दिखाई देता है। Continue anyway QQL शुरू करने का प्रयास करता है;
Cancel उसे बंद कर देता है। यदि कोई अनिवार्य प्रोग्राम फ़ाइल नहीं मिलती, तो संदेश
में Close दिखाई देता है, क्योंकि पैकेज को फिर से डाउनलोड करके पूरी तरह निकालना
आवश्यक है।

Wine समर्थन Experimental है। Wine में Media Foundation न होने पर प्रोग्राम
शुरू नहीं हो सकता या ऑडियो और मीडिया सुविधाएँ काम नहीं कर सकतीं।

MICROSOFT VISUAL C++ RUNTIME
----------------------------

पूरे पैकेज में Microsoft Visual C++ x64 की ये runtime फ़ाइलें शामिल हैं:

msvcp140.dll
vcruntime140.dll
vcruntime140_1.dll

यदि इनमें से कोई फ़ाइल नहीं मिले, तो पूरा QuisquisLingo Windows पैकेज फिर से
डाउनलोड करें और पूरी तरह निकालें। Runtime installer केवल Microsoft के आधिकारिक
स्रोत से लें और अलग-अलग DLL फ़ाइलें कभी भी तृतीय-पक्ष वेबसाइट से डाउनलोड न करें।

Microsoft की आधिकारिक जानकारी:
https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist

MEDIA FOUNDATION
----------------

Windows N संस्करणों में ऑडियो और मीडिया कार्यों के लिए Microsoft Media Feature
Pack आवश्यक हो सकता है। Media Feature Pack सामान्यतः Windows Optional Features
में उपलब्ध होता है। Windows N के कुछ संस्करणों में यह Optional Features में
उपलब्ध नहीं हो सकता। ऐसी स्थिति में अपनी Windows संस्करण के लिए उपयुक्त Media
Feature Pack Microsoft वेबसाइट से डाउनलोड करें।

Media Feature Pack इंस्टॉल करने के बाद Windows को पुनः आरंभ करें। QuisquisLingo
इसे अपने आप डाउनलोड या इंस्टॉल नहीं करता और सिस्टम सेटिंग नहीं बदलता।

TEXT-TO-SPEECH
--------------

QuisquisLingo Windows में इंस्टॉल की गई वाक् आवाज़ों का उपयोग करता है। उपलब्ध
भाषाएँ और आवाज़ें कंप्यूटर में इंस्टॉल किए गए Windows भाषा और आवाज़ घटकों पर
निर्भर करती हैं। यदि कोई संगत आवाज़ उपलब्ध न हो, तो Windows settings के माध्यम
से उपयुक्त घटक इंस्टॉल करें।

Audio Settings > Test Voice केवल आपके द्वारा दर्ज किया गया पाठ बोलता है और
चुने गए पाठ्यक्रम में निर्धारित आवाज़ की भाषा का उपयोग करता है।

लॉग और निदान
------------

मुख्य crash log यहाँ संग्रहीत होता है:

Documents\QuisquisLingo\Logs\quisquislingo_crash.log

आरंभिक जाँच का log यहाँ संग्रहीत होता है:

%LOCALAPPDATA%\QuisquisLingo\Logs\quisquislingo_launcher.log

Settings > Debug में निदान विकल्प उपलब्ध हैं। Logs स्थानीय कंप्यूटर पर रहते हैं
और अपने आप upload नहीं होते।

समस्या निवारण
-------------

1. पूरी ZIP फ़ाइल को पूरी तरह निकालें।
2. निकाले गए पैकेज से QuisquisLingo.exe चलाएँ।
3. यदि runtime DLL के न मिलने की सूचना मिले, तो आधिकारिक Microsoft runtime
   installer पर विचार करने से पहले पूरा पैकेज फिर डाउनलोड करके निकालें।
4. यदि Media Feature Pack आवश्यक हो, तो ऊपर दिए निर्देशों का पालन करें और
   इंस्टॉल करने के बाद Windows को पुनः आरंभ करें।
5. यदि QQL फिर भी शुरू न हो, तो सहायता के लिए पूरा error संदेश और उपलब्ध log
   फ़ाइलें सुरक्षित रखें।
