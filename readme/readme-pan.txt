QuisquisLingo - Windows ਮਾਰਗਦਰਸ਼ਿਕਾ
==================================

QuisquisLingo ਭਾਸ਼ਾ ਸਿੱਖਣ ਵਾਲਿਆਂ ਅਤੇ ਕੋਰਸ ਬਣਾਉਣ ਵਾਲਿਆਂ ਲਈ ਭਾਸ਼ਾ-ਸਿਖਲਾਈ
ਐਪਲੀਕੇਸ਼ਨ ਹੈ। ਇਹ ਢਾਂਚਾਬੱਧ ਪਾਠਾਂ, ਪਰਸਪਰ ਅਭਿਆਸਾਂ, ਆਡੀਓ ਗਤੀਵਿਧੀਆਂ ਅਤੇ ਦੁਹਰਾਈ ਦੇ
ਸਾਧਨਾਂ ਨੂੰ ਜੋੜਦੀ ਹੈ ਅਤੇ ਭਾਸ਼ਾ ਦੇ ਕੋਰਸ ਬਣਾਉਣ ਤੇ ਸੋਧਣ ਲਈ ਸਾਧਨ ਵੀ ਦਿੰਦੀ ਹੈ।

ਇਹ ਭਾਸ਼ਾ ਸਿੱਖਣ ਦੇ ਚਾਹਵਾਨ ਲੋਕਾਂ ਦੇ ਨਾਲ-ਨਾਲ ਆਪਣੇ ਕੋਰਸ ਬਣਾਉਣ ਦੇ ਚਾਹਵਾਨ ਲੇਖਕਾਂ,
ਅਧਿਆਪਕਾਂ ਅਤੇ ਹੋਰ ਵਰਤੋਂਕਾਰਾਂ ਲਈ ਤਿਆਰ ਕੀਤੀ ਗਈ ਹੈ।

QuisquisLingo ਕਿਵੇਂ ਕੰਮ ਕਰਦੀ ਹੈ, ਇਸਦੀ ਛੋਟੀ ਜਿਹੀ ਦ੍ਰਿਸ਼ ਜਾਣਕਾਰੀ ਲਈ ਐਪਲੀਕੇਸ਼ਨ
ਪੈਕੇਜ ਵਿੱਚ ਸ਼ਾਮਲ QQL infographic.png ਵੇਖੋ।

QuisquisLingo ਸ਼ੁਰੂ ਕਰਨ ਲਈ QuisquisLingo.exe ਚਲਾਓ।

ਪੈਕੇਜ ਦੀ ਵਰਤੋਂ
--------------

ਇਸ ਪੈਕੇਜ ਵਿੱਚ QQL ਐਪਲੀਕੇਸ਼ਨ ਹੈ। ਸ਼ੁਰੂ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ ਪੂਰੀ ZIP ਆਰਕਾਈਵ ਨੂੰ ਕੱਢੋ
ਅਤੇ ਦਿੱਤੀਆਂ ਸਾਰੀਆਂ ਫਾਈਲਾਂ ਅਤੇ data ਫੋਲਡਰ ਨੂੰ ਇਕੱਠੇ ਰੱਖੋ। ਵੱਖਰੀਆਂ EXE ਜਾਂ DLL
ਫਾਈਲਾਂ ਨੂੰ ਵੰਡੋ, ਹਿਲਾਓ, ਮਿਟਾਓ ਜਾਂ ਉਹਨਾਂ ਦੇ ਨਾਂ ਨਾ ਬਦਲੋ।

ਸ਼ੁਰੂਆਤੀ ਜਾਂਚਾਂ
--------------

ਸ਼ੁਰੂ ਹੋਣ ਤੋਂ ਪਹਿਲਾਂ QuisquisLingo ਲੋੜੀਂਦੀਆਂ ਪੈਕੇਜ ਫਾਈਲਾਂ, Windows ਅਨੁਕੂਲਤਾ ਅਤੇ
Media Foundation ਦੀ ਜਾਂਚ ਕਰਦੀ ਹੈ। ਇਹ ਜਾਂਚਾਂ ਕਦੇ ਵੀ ਸਾਫਟਵੇਅਰ ਡਾਊਨਲੋਡ ਜਾਂ ਇੰਸਟਾਲ
ਨਹੀਂ ਕਰਦੀਆਂ, ਪ੍ਰਬੰਧਕ ਅਧਿਕਾਰ ਨਹੀਂ ਮੰਗਦੀਆਂ, registry ਜਾਂ Windows ਨੂੰ ਨਹੀਂ ਬਦਲਦੀਆਂ।

ਜੇ ਕਿਸੇ ਸਮੱਸਿਆ ਦੇ ਬਾਵਜੂਦ ਅੱਗੇ ਵਧਿਆ ਜਾ ਸਕਦਾ ਹੋਵੇ, ਤਾਂ Continue anyway ਅਤੇ Cancel
ਵਾਲਾ ਇੱਕ ਸੰਦੇਸ਼ ਦਿਖਾਈ ਦਿੰਦਾ ਹੈ। Continue anyway QQL ਸ਼ੁਰੂ ਕਰਨ ਦੀ ਕੋਸ਼ਿਸ਼ ਕਰਦਾ ਹੈ;
Cancel ਇਸਨੂੰ ਬੰਦ ਕਰਦਾ ਹੈ। ਜੇ ਕੋਈ ਲਾਜ਼ਮੀ ਪ੍ਰੋਗਰਾਮ ਫਾਈਲ ਨਹੀਂ ਹੈ, ਤਾਂ ਸੰਦੇਸ਼ Close
ਦਿੰਦਾ ਹੈ, ਕਿਉਂਕਿ ਪੈਕੇਜ ਦੁਬਾਰਾ ਡਾਊਨਲੋਡ ਕਰਕੇ ਪੂਰੀ ਤਰ੍ਹਾਂ ਕੱਢਣਾ ਲਾਜ਼ਮੀ ਹੈ।

Wine ਸਹਾਇਤਾ Experimental ਹੈ। Wine ਵਿੱਚ Media Foundation ਨਾ ਹੋਣ ਕਰਕੇ ਪ੍ਰੋਗਰਾਮ
ਸ਼ੁਰੂ ਨਹੀਂ ਹੋ ਸਕਦਾ ਜਾਂ ਆਡੀਓ ਅਤੇ ਮੀਡੀਆ ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ ਕੰਮ ਨਹੀਂ ਕਰ ਸਕਦੀਆਂ।

MICROSOFT VISUAL C++ RUNTIME
----------------------------

ਪੂਰੇ ਪੈਕੇਜ ਵਿੱਚ ਇਹ Microsoft Visual C++ x64 runtime ਫਾਈਲਾਂ ਸ਼ਾਮਲ ਹਨ:

msvcp140.dll
vcruntime140.dll
vcruntime140_1.dll

ਜੇ ਇਹਨਾਂ ਵਿੱਚੋਂ ਕੋਈ ਫਾਈਲ ਨਾ ਹੋਵੇ, ਤਾਂ ਪੂਰਾ QuisquisLingo Windows ਪੈਕੇਜ ਦੁਬਾਰਾ
ਡਾਊਨਲੋਡ ਕਰਕੇ ਪੂਰੀ ਤਰ੍ਹਾਂ ਕੱਢੋ। Runtime installer ਲਈ ਸਿਰਫ Microsoft ਦੇ ਅਧਿਕਾਰਤ
ਸਰੋਤ ਵਰਤੋ ਅਤੇ ਤੀਜੀ ਧਿਰ ਦੀਆਂ ਵੈੱਬਸਾਈਟਾਂ ਤੋਂ ਵੱਖਰੀਆਂ DLL ਫਾਈਲਾਂ ਕਦੇ ਡਾਊਨਲੋਡ ਨਾ ਕਰੋ।

Microsoft ਦੀ ਅਧਿਕਾਰਤ ਜਾਣਕਾਰੀ:
https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist

MEDIA FOUNDATION
----------------

Windows N ਐਡੀਸ਼ਨਾਂ ਵਿੱਚ ਆਡੀਓ ਅਤੇ ਮੀਡੀਆ ਕਾਰਜਾਂ ਲਈ Microsoft Media Feature Pack
ਦੀ ਲੋੜ ਹੋ ਸਕਦੀ ਹੈ। Media Feature Pack ਆਮ ਤੌਰ 'ਤੇ Windows Optional Features ਵਿੱਚ
ਮਿਲਦਾ ਹੈ। Windows N ਦੇ ਕੁਝ ਸੰਸਕਰਣਾਂ ਵਿੱਚ Media Feature Pack Optional Features
ਵਿੱਚ ਨਾ ਮਿਲੇ। ਉਸ ਹਾਲਤ ਵਿੱਚ ਆਪਣੇ Windows ਸੰਸਕਰਣ ਲਈ ਢੁਕਵਾਂ Media Feature Pack
Microsoft ਦੀ ਵੈੱਬਸਾਈਟ ਤੋਂ ਡਾਊਨਲੋਡ ਕਰੋ।

Media Feature Pack ਇੰਸਟਾਲ ਕਰਨ ਤੋਂ ਬਾਅਦ Windows ਨੂੰ ਮੁੜ ਚਾਲੂ ਕਰੋ। QuisquisLingo
ਇਸਨੂੰ ਆਪਣੇ ਆਪ ਡਾਊਨਲੋਡ ਜਾਂ ਇੰਸਟਾਲ ਨਹੀਂ ਕਰਦੀ ਅਤੇ ਸਿਸਟਮ ਸੈਟਿੰਗਾਂ ਨਹੀਂ ਬਦਲਦੀ।

ਲਿਖਤ ਤੋਂ ਬੋਲੀ
-------------

QuisquisLingo Windows ਵਿੱਚ ਇੰਸਟਾਲ ਕੀਤੀਆਂ ਬੋਲਣ ਵਾਲੀਆਂ ਆਵਾਜ਼ਾਂ ਵਰਤਦੀ ਹੈ। ਉਪਲਬਧ
ਭਾਸ਼ਾਵਾਂ ਅਤੇ ਆਵਾਜ਼ਾਂ ਕੰਪਿਊਟਰ ਵਿੱਚ ਇੰਸਟਾਲ ਕੀਤੇ Windows ਭਾਸ਼ਾ ਅਤੇ ਆਵਾਜ਼ ਭਾਗਾਂ 'ਤੇ
ਨਿਰਭਰ ਕਰਦੀਆਂ ਹਨ। ਜੇ ਕੋਈ ਅਨੁਕੂਲ ਆਵਾਜ਼ ਨਾ ਹੋਵੇ, ਤਾਂ Windows ਸੈਟਿੰਗਾਂ ਰਾਹੀਂ ਢੁਕਵਾਂ
ਭਾਗ ਇੰਸਟਾਲ ਕਰੋ।

Audio Settings > Test Voice ਸਿਰਫ ਤੁਹਾਡੇ ਵੱਲੋਂ ਦਰਜ ਕੀਤੀ ਲਿਖਤ ਬੋਲਦਾ ਹੈ ਅਤੇ ਚੁਣੇ
ਗਏ ਕੋਰਸ ਵਿੱਚ ਸੈੱਟ ਕੀਤੀ ਆਵਾਜ਼ ਦੀ ਭਾਸ਼ਾ ਵਰਤਦਾ ਹੈ।

ਲਾਗ ਅਤੇ ਜਾਂਚ
------------

ਮੁੱਖ crash log ਇੱਥੇ ਸੰਭਾਲਿਆ ਜਾਂਦਾ ਹੈ:

Documents\QuisquisLingo\Logs\quisquislingo_crash.log

ਸ਼ੁਰੂਆਤੀ ਜਾਂਚ ਦਾ log ਇੱਥੇ ਸੰਭਾਲਿਆ ਜਾਂਦਾ ਹੈ:

%LOCALAPPDATA%\QuisquisLingo\Logs\quisquislingo_launcher.log

Settings > Debug ਜਾਂਚ ਦੇ ਵਿਕਲਪ ਦਿਖਾਉਂਦਾ ਹੈ। Log ਫਾਈਲਾਂ ਸਥਾਨਕ ਕੰਪਿਊਟਰ ਉੱਤੇ ਰਹਿੰਦੀਆਂ
ਹਨ ਅਤੇ ਆਪਣੇ ਆਪ ਅੱਪਲੋਡ ਨਹੀਂ ਹੁੰਦੀਆਂ।

ਸਮੱਸਿਆ ਦਾ ਹੱਲ
-------------

1. ਪੂਰੀ ZIP ਆਰਕਾਈਵ ਨੂੰ ਪੂਰੀ ਤਰ੍ਹਾਂ ਕੱਢੋ।
2. ਕੱਢੇ ਗਏ ਪੈਕੇਜ ਤੋਂ QuisquisLingo.exe ਚਲਾਓ।
3. ਜੇ runtime DLL ਨਾ ਹੋਣ ਦੀ ਸੂਚਨਾ ਮਿਲੇ, ਤਾਂ ਅਧਿਕਾਰਤ Microsoft runtime installer
   ਬਾਰੇ ਸੋਚਣ ਤੋਂ ਪਹਿਲਾਂ ਪੂਰਾ ਪੈਕੇਜ ਦੁਬਾਰਾ ਡਾਊਨਲੋਡ ਕਰਕੇ ਕੱਢੋ।
4. ਜੇ Media Feature Pack ਦੀ ਲੋੜ ਹੋਵੇ, ਤਾਂ ਉੱਪਰ ਦਿੱਤੇ ਮਾਰਗਦਰਸ਼ਨ ਦੀ ਪਾਲਣਾ ਕਰੋ ਅਤੇ
   ਇੰਸਟਾਲ ਕਰਨ ਤੋਂ ਬਾਅਦ Windows ਨੂੰ ਮੁੜ ਚਾਲੂ ਕਰੋ।
5. ਜੇ QQL ਅਜੇ ਵੀ ਸ਼ੁਰੂ ਨਾ ਹੋਵੇ, ਤਾਂ ਸਹਾਇਤਾ ਲਈ ਪੂਰਾ ਗਲਤੀ ਸੰਦੇਸ਼ ਅਤੇ ਉਪਲਬਧ log
   ਫਾਈਲਾਂ ਸੰਭਾਲ ਕੇ ਰੱਖੋ।
