QuisquisLingo - Windows માર્ગદર્શિકા
===================================

QuisquisLingo ભાષા શીખનારાઓ અને અભ્યાસક્રમ બનાવનારાઓ માટેની ભાષા-શિક્ષણ
એપ્લિકેશન છે. તે વ્યવસ્થિત પાઠ, પરસ્પરક્રિયાત્મક કસરતો, ઑડિયો પ્રવૃત્તિઓ અને
પુનરાવર્તનનાં સાધનોને જોડે છે, તેમજ ભાષાના અભ્યાસક્રમ બનાવવા અને સંપાદિત કરવા
માટેનાં સાધનો પણ આપે છે.

તે ભાષા શીખવા ઇચ્છતા લોકો માટે તેમજ પોતાના અભ્યાસક્રમ બનાવવા ઇચ્છતા લેખકો,
શિક્ષકો અને અન્ય વપરાશકર્તાઓ માટે રચવામાં આવી છે.

QuisquisLingo કેવી રીતે કાર્ય કરે છે તેનો ઝડપી દૃશ્ય પરિચય મેળવવા માટે એપ્લિકેશન
પેકેજમાં સામેલ QQL infographic.png જુઓ.

QuisquisLingo શરૂ કરવા માટે QuisquisLingo.exe ચલાવો.

પેકેજનો ઉપયોગ
-------------

આ પેકેજમાં QQL એપ્લિકેશન છે. શરૂ કરતાં પહેલાં સમગ્ર ZIP આર્કાઇવ બહાર કાઢો અને
આપેલી બધી ફાઇલો તથા data ફોલ્ડરને સાથે રાખો. અલગ EXE અથવા DLL ફાઇલોનું વિતરણ,
સ્થાનાંતરણ, કાઢી નાખવું કે નામ બદલવું નહીં.

શરૂઆતની તપાસ
------------

શરૂ કરતાં પહેલાં QuisquisLingo જરૂરી પેકેજ ફાઇલો, Windows સુસંગતતા અને Media
Foundation તપાસે છે. આ તપાસ ક્યારેય સૉફ્ટવેર ડાઉનલોડ કે ઇન્સ્ટૉલ કરતી નથી,
વહીવટકર્તા પરવાનગી માગતી નથી, registry કે Windowsમાં ફેરફાર કરતી નથી.

સમસ્યા હોવા છતાં આગળ વધી શકાય તો Continue anyway અને Cancel ધરાવતો એક જ સંદેશ
દેખાય છે. Continue anyway QQL શરૂ કરવાનો પ્રયાસ કરે છે; Cancel તેને બંધ કરે છે.
આવશ્યક પ્રોગ્રામ ફાઇલ ન હોય તો સંદેશ Close આપે છે, કારણ કે પેકેજ ફરી ડાઉનલોડ
કરીને સંપૂર્ણપણે બહાર કાઢવું જરૂરી છે.

Wine આધાર Experimental છે. Wineમાં Media Foundation ન હોય તો શરૂઆત અટકી શકે
અથવા ઑડિયો અને મીડિયા સુવિધાઓ કામ ન કરી શકે.

MICROSOFT VISUAL C++ RUNTIME
----------------------------

સંપૂર્ણ પેકેજમાં આ Microsoft Visual C++ x64 runtime ફાઇલો સામેલ છે:

msvcp140.dll
vcruntime140.dll
vcruntime140_1.dll

તેમાંથી કોઈ ફાઇલ ન હોય તો સંપૂર્ણ QuisquisLingo Windows પેકેજ ફરી ડાઉનલોડ કરીને
સંપૂર્ણપણે બહાર કાઢો. Runtime installer માટે માત્ર Microsoftના અધિકૃત સ્રોતોનો
ઉપયોગ કરો અને તૃતીય-પક્ષ વેબસાઇટ પરથી અલગ DLL ફાઇલો ક્યારેય ડાઉનલોડ ન કરો.

Microsoftની અધિકૃત માહિતી:
https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist

MEDIA FOUNDATION
----------------

Windows N આવૃત્તિઓમાં ઑડિયો અને મીડિયા કાર્ય માટે Microsoft Media Feature Packની
જરૂર પડી શકે છે. Media Feature Pack સામાન્ય રીતે Windows Optional Featuresમાં
ઉપલબ્ધ હોય છે. Windows Nની કેટલીક આવૃત્તિઓમાં Media Feature Pack Optional
Featuresમાં ઉપલબ્ધ ન હોઈ શકે. એવા સમયે તમારી Windows આવૃત્તિ માટે યોગ્ય Media
Feature Pack Microsoftની વેબસાઇટ પરથી ડાઉનલોડ કરો.

Media Feature Pack ઇન્સ્ટૉલ કર્યા પછી Windows ફરી શરૂ કરો. QuisquisLingo તેને
આપમેળે ડાઉનલોડ કે ઇન્સ્ટૉલ કરતું નથી અને સિસ્ટમ સેટિંગ્સ બદલતું નથી.

લખાણને વાણીમાં ફેરવવું
----------------------

QuisquisLingo Windowsમાં ઇન્સ્ટૉલ કરેલા વાણીના અવાજો વાપરે છે. ઉપલબ્ધ ભાષા અને
અવાજો કમ્પ્યુટરમાં ઇન્સ્ટૉલ કરેલા Windows ભાષા અને અવાજના ઘટકો પર આધારિત છે.
સુસંગત અવાજ ન હોય તો Windows સેટિંગ્સ દ્વારા યોગ્ય ઘટક ઇન્સ્ટૉલ કરો.

Audio Settings > Test Voice તમે દાખલ કરેલું લખાણ જ બોલે છે અને પસંદ કરેલા
અભ્યાસક્રમમાં નક્કી કરેલી અવાજની ભાષા વાપરે છે.

લૉગ અને નિદાન
-------------

મુખ્ય crash log અહીં સંગ્રહિત થાય છે:

Documents\QuisquisLingo\Logs\quisquislingo_crash.log

શરૂઆતની તપાસનો log અહીં સંગ્રહિત થાય છે:

%LOCALAPPDATA%\QuisquisLingo\Logs\quisquislingo_launcher.log

Settings > Debug નિદાન વિકલ્પો બતાવે છે. Log ફાઇલો સ્થાનિક કમ્પ્યુટરમાં રહે છે
અને આપમેળે અપલોડ થતી નથી.

સમસ્યાનું નિરાકરણ
-----------------

1. સમગ્ર ZIP આર્કાઇવ સંપૂર્ણપણે બહાર કાઢો.
2. બહાર કાઢેલા પેકેજમાંથી QuisquisLingo.exe ચલાવો.
3. Runtime DLL ન હોવાનું જણાવાય તો અધિકૃત Microsoft runtime installerનો વિચાર
   કરતાં પહેલાં સંપૂર્ણ પેકેજ ફરી ડાઉનલોડ કરીને બહાર કાઢો.
4. Media Feature Pack જરૂરી હોય તો ઉપરનું માર્ગદર્શન અનુસરો અને ઇન્સ્ટૉલ કર્યા
   પછી Windows ફરી શરૂ કરો.
5. QQL હજી શરૂ ન થાય તો મદદ માટે સંપૂર્ણ ભૂલ સંદેશ અને ઉપલબ્ધ log ફાઇલો રાખો.
