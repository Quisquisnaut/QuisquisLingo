QuisquisLingo - Windows മാർഗ്ഗനിർദ്ദേശം
=====================================

QuisquisLingo ഭാഷ പഠിക്കുന്നവർക്കും കോഴ്സുകൾ സൃഷ്ടിക്കുന്നവർക്കുമുള്ള ഭാഷാപഠന
ആപ്ലിക്കേഷനാണ്. ക്രമീകരിച്ച പാഠങ്ങൾ, സംവേദനാത്മക വ്യായാമങ്ങൾ, ഓഡിയോ പ്രവർത്തനങ്ങൾ,
ആവർത്തന ഉപകരണങ്ങൾ എന്നിവ സംയോജിപ്പിക്കുന്നതിനൊപ്പം ഭാഷാ കോഴ്സുകൾ സൃഷ്ടിക്കാനും
തിരുത്താനുമുള്ള ഉപകരണങ്ങളും ഇത് നൽകുന്നു.

ഒരു ഭാഷ പഠിക്കാൻ ആഗ്രഹിക്കുന്നവർക്കും സ്വന്തം കോഴ്സുകൾ നിർമ്മിക്കാൻ ആഗ്രഹിക്കുന്ന
രചയിതാക്കൾക്കും അധ്യാപകർക്കും മറ്റ് ഉപയോക്താക്കൾക്കും വേണ്ടിയാണ് ഇത് രൂപകൽപ്പന
ചെയ്തിരിക്കുന്നത്.

QuisquisLingo എങ്ങനെ പ്രവർത്തിക്കുന്നു എന്നതിന്റെ വേഗത്തിലുള്ള ദൃശ്യ അവലോകനത്തിന്,
ആപ്ലിക്കേഷൻ പാക്കേജിൽ ഉൾപ്പെടുത്തിയ QQL infographic.png കാണുക.

QuisquisLingo ആരംഭിക്കാൻ QuisquisLingo.exe പ്രവർത്തിപ്പിക്കുക.

പാക്കേജ് ഉപയോഗിക്കൽ
------------------

ഈ പാക്കേജിൽ QQL ആപ്ലിക്കേഷൻ അടങ്ങിയിരിക്കുന്നു. ആരംഭിക്കുന്നതിന് മുമ്പ് മുഴുവൻ ZIP
ആർക്കൈവും പുറത്തെടുത്ത് നൽകിയ എല്ലാ ഫയലുകളും data ഫോൾഡറും ഒരുമിച്ച് സൂക്ഷിക്കുക.
വ്യക്തിഗത EXE അല്ലെങ്കിൽ DLL ഫയലുകൾ വിതരണം ചെയ്യുകയോ മാറ്റുകയോ ഇല്ലാതാക്കുകയോ
പേരുമാറ്റുകയോ ചെയ്യരുത്.

ആരംഭ പരിശോധനകൾ
---------------

ആരംഭിക്കുന്നതിന് മുമ്പ് QuisquisLingo ആവശ്യമായ പാക്കേജ് ഫയലുകൾ, Windows
അനുയോജ്യത, Media Foundation എന്നിവ പരിശോധിക്കുന്നു. ഈ പരിശോധനകൾ ഒരിക്കലും
സോഫ്റ്റ്‌വെയർ ഡൗൺലോഡ് ചെയ്യുകയോ ഇൻസ്റ്റാൾ ചെയ്യുകയോ, അഡ്മിനിസ്ട്രേറ്റർ അനുമതി
ചോദിക്കുകയോ, registry അല്ലെങ്കിൽ Windows മാറ്റുകയോ ചെയ്യുന്നില്ല.

ഒരു പ്രശ്നമുണ്ടെങ്കിലും തുടരാനാകുമെങ്കിൽ Continue anyway, Cancel എന്നിവയുള്ള ഒരൊറ്റ
സന്ദേശം പ്രത്യക്ഷപ്പെടും. Continue anyway QQL ആരംഭിക്കാൻ ശ്രമിക്കും; Cancel അത്
അടയ്ക്കും. അത്യാവശ്യമായ പ്രോഗ്രാം ഫയൽ ഇല്ലെങ്കിൽ, പാക്കേജ് വീണ്ടും ഡൗൺലോഡ് ചെയ്ത്
പൂർണ്ണമായി പുറത്തെടുക്കേണ്ടതിനാൽ സന്ദേശം Close നൽകും.

Wine പിന്തുണ Experimental നിലയിലാണ്. Wine-ൽ Media Foundation ഇല്ലാത്തത് ആരംഭം
തടയുകയോ ഓഡിയോ, മീഡിയ സവിശേഷതകൾ പ്രവർത്തിക്കാതിരിക്കുകയോ ചെയ്യാം.

MICROSOFT VISUAL C++ RUNTIME
----------------------------

പൂർണ്ണ പാക്കേജിൽ ഇനിപ്പറയുന്ന Microsoft Visual C++ x64 runtime ഫയലുകൾ ഉണ്ട്:

msvcp140.dll
vcruntime140.dll
vcruntime140_1.dll

ഇവയിൽ ഒന്ന് ഇല്ലെങ്കിൽ, പൂർണ്ണ QuisquisLingo Windows പാക്കേജ് വീണ്ടും ഡൗൺലോഡ്
ചെയ്ത് പൂർണ്ണമായി പുറത്തെടുക്കുക. Runtime installer-നായി Microsoft-ന്റെ ഔദ്യോഗിക
ഉറവിടങ്ങൾ മാത്രം ഉപയോഗിക്കുക; മൂന്നാം കക്ഷി വെബ്‌സൈറ്റുകളിൽ നിന്ന് വ്യക്തിഗത DLL
ഫയലുകൾ ഒരിക്കലും ഡൗൺലോഡ് ചെയ്യരുത്.

Microsoft-ന്റെ ഔദ്യോഗിക വിവരങ്ങൾ:
https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist

MEDIA FOUNDATION
----------------

ഓഡിയോ, മീഡിയ പ്രവർത്തനങ്ങൾക്ക് Windows N പതിപ്പുകളിൽ Microsoft Media Feature
Pack ആവശ്യമായി വന്നേക്കാം. Media Feature Pack സാധാരണയായി Windows Optional
Features-ൽ ലഭ്യമാണ്. Windows N-ന്റെ ചില പതിപ്പുകളിൽ Media Feature Pack Optional
Features-ൽ ലഭ്യമാകാതിരിക്കാം. അത്തരം സാഹചര്യത്തിൽ നിങ്ങളുടെ Windows പതിപ്പിന്
അനുയോജ്യമായ Media Feature Pack Microsoft വെബ്‌സൈറ്റിൽ നിന്ന് ഡൗൺലോഡ് ചെയ്യുക.

Media Feature Pack ഇൻസ്റ്റാൾ ചെയ്ത ശേഷം Windows പുനരാരംഭിക്കുക. QuisquisLingo
അത് സ്വയമേവ ഡൗൺലോഡ് ചെയ്യുകയോ ഇൻസ്റ്റാൾ ചെയ്യുകയോ ഇല്ല; സിസ്റ്റം ക്രമീകരണങ്ങളും
മാറ്റില്ല.

വാചകത്തെ സംസാരമാക്കൽ
--------------------

QuisquisLingo Windows-ൽ ഇൻസ്റ്റാൾ ചെയ്ത സംസാര ശബ്ദങ്ങൾ ഉപയോഗിക്കുന്നു. ലഭ്യമായ
ഭാഷകളും ശബ്ദങ്ങളും കമ്പ്യൂട്ടറിൽ ഇൻസ്റ്റാൾ ചെയ്ത Windows ഭാഷാ, ശബ്ദ ഘടകങ്ങളെ
ആശ്രയിച്ചിരിക്കുന്നു. അനുയോജ്യമായ ശബ്ദം ലഭ്യമല്ലെങ്കിൽ Windows ക്രമീകരണങ്ങളിലൂടെ
ഉചിതമായ ഘടകം ഇൻസ്റ്റാൾ ചെയ്യുക.

Audio Settings > Test Voice നിങ്ങൾ നൽകിയ വാചകം മാത്രം സംസാരിക്കുകയും തിരഞ്ഞെടുത്ത
കോഴ്സിൽ ക്രമീകരിച്ച ശബ്ദഭാഷ ഉപയോഗിക്കുകയും ചെയ്യുന്നു.

ലോഗുകളും പരിശോധനയും
-------------------

പ്രധാന crash log ഇവിടെ സൂക്ഷിക്കുന്നു:

Documents\QuisquisLingo\Logs\quisquislingo_crash.log

ആരംഭ പരിശോധനയുടെ log ഇവിടെ സൂക്ഷിക്കുന്നു:

%LOCALAPPDATA%\QuisquisLingo\Logs\quisquislingo_launcher.log

Settings > Debug പരിശോധനാ ഓപ്ഷനുകൾ കാണിക്കുന്നു. Log ഫയലുകൾ പ്രാദേശിക
കമ്പ്യൂട്ടറിൽ തന്നെ നിലനിൽക്കും; സ്വയമേവ അപ്‌ലോഡ് ചെയ്യില്ല.

പ്രശ്നപരിഹാരം
-------------

1. മുഴുവൻ ZIP ആർക്കൈവും പൂർണ്ണമായി പുറത്തെടുക്കുക.
2. പുറത്തെടുത്ത പാക്കേജിൽ നിന്ന് QuisquisLingo.exe പ്രവർത്തിപ്പിക്കുക.
3. Runtime DLL ഇല്ലെന്ന് അറിയിച്ചാൽ, ഔദ്യോഗിക Microsoft runtime installer
   പരിഗണിക്കുന്നതിന് മുമ്പ് പൂർണ്ണ പാക്കേജ് വീണ്ടും ഡൗൺലോഡ് ചെയ്ത് പുറത്തെടുക്കുക.
4. Media Feature Pack ആവശ്യമെങ്കിൽ മുകളിലുള്ള മാർഗ്ഗനിർദ്ദേശം പാലിച്ച് ഇൻസ്റ്റാൾ
   ചെയ്ത ശേഷം Windows പുനരാരംഭിക്കുക.
5. QQL ഇപ്പോഴും ആരംഭിക്കുന്നില്ലെങ്കിൽ സഹായത്തിനായി പൂർണ്ണ പിശക് സന്ദേശവും ലഭ്യമായ
   log ഫയലുകളും സൂക്ഷിക്കുക.
