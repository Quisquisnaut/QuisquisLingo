QuisquisLingo - Praecepta Windows
================================

QuisquisLingo est instrumentum ad linguas discendas, tam discentibus quam
conditoribus cursuum destinatum. Lectiones ordinatas, exercitationes mutuas,
opera sonora atque instrumenta repetitionis coniungit; instrumenta quoque ad
cursus linguarum creandos et emendandos praebet.

Paratum est et iis qui linguam discere volunt et auctoribus, magistris aliisque
usoribus qui cursus suos componere volunt.

Ut celerem explicationem imaginibus expressam de ratione qua QuisquisLingo
operatur videas, inspice QQL infographic.png, quod in fasciculo applicationis
includitur.

Ut QuisquisLingo incipias, exsequere QuisquisLingo.exe.

USUS FASCICULI
--------------

Hic fasciculus applicationem QQL continet. Totum archivum ZIP extrahe antequam
applicationem incipias, omnesque res traditas et directorium data coniuncta
serva. Singula documenta EXE vel DLL ne distribuas, moveas, deleas neve renomes.

EXAMINA INITIALIA
-----------------

Ante initium QuisquisLingo documenta necessaria fasciculi, congruentiam cum
Windows et Media Foundation examinat. Haec examina numquam programmata deponunt
aut instituunt, iura administratoris poscunt, registry mutant vel Windows
commutant.

Si post difficultatem progredi licet, unum nuntium cum Continue anyway et Cancel
vides. Continue anyway QQL incipere conatur; Cancel id claudit. Si documentum
programmatum necessarium deest, nuntius Close praebet, quia fasciculus iterum
deponendus totusque extrahendus est.

Auxilium Wine est Experimental. Si Media Foundation sub Wine deest, initium
impediri potest aut functiones soni et mediorum operari non possunt.

MICROSOFT VISUAL C++ RUNTIME
----------------------------

Fasciculus plenus haec documenta runtime Microsoft Visual C++ x64 continet:

msvcp140.dll
vcruntime140.dll
vcruntime140_1.dll

Si quid eorum deest, fasciculum QuisquisLingo Windows plenum iterum depone atque
totum extrahe. Ad runtime installer solos fontes publicos Microsoft adhibe, nec
singula documenta DLL umquam e paginis alienis depone.

Notitia publica Microsoft:
https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist

MEDIA FOUNDATION
----------------

Editiones Windows N Microsoft Media Feature Pack ad functiones soni et mediorum
fortasse requirunt. Media Feature Pack plerumque inter Windows Optional Features
praesto est. In quibusdam versionibus Windows N, Media Feature Pack inter
Optional Features fortasse non praesto est. Tum Media Feature Pack versioni tuae
Windows aptum e situ Microsoft depone.

Post Media Feature Pack institutum Windows denuo incipe. QuisquisLingo id sponte
non deponit neque instituit nec ordinationes systematis mutat.

TEXT-TO-SPEECH
--------------

QuisquisLingo vocibus loquentibus in Windows institutis utitur. Linguae et voces
quae praesto sunt a partibus linguae vocisque Windows in computatro institutis
pendent. Si nulla vox congruens praesto est, partem aptam per ordinationes
Windows institue.

Audio Settings > Test Voice solum verba a te inserta pronuntiat et lingua vocis
in cursu electo configurata utitur.

COMMENTARII ET DIAGNOSIS
------------------------

Praecipuus crash log hic servatur:

Documents\QuisquisLingo\Logs\quisquislingo_crash.log

Log examinum initialium hic servatur:

%LOCALAPPDATA%\QuisquisLingo\Logs\quisquislingo_launcher.log

Settings > Debug optiones diagnosis ostendit. Log in computatro locali manent
nec sponte transmittuntur.

DIFFICULTATUM REMEDIA
---------------------

1. Totum archivum ZIP omnino extrahe.
2. QuisquisLingo.exe ex fasciculo extracto exsequere.
3. Si nuntiatur runtime DLL deesse, fasciculum plenum iterum depone atque
   extrahe antequam runtime installer publicum Microsoft adhibere cogites.
4. Si Media Feature Pack requiritur, praecepta superiora sequere et Windows post
   institutionem denuo incipe.
5. Si QQL adhuc non incipit, nuntium erroris plenum et documenta log quae praesto
   sunt ad auxilium serva.
