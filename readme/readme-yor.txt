QuisquisLingo - Ìtọ́sọ́nà Windows
================================

QuisquisLingo jẹ́ ìṣàfilọ́lẹ̀ ìkẹ́kọ̀ọ́ èdè fún àwọn akẹ́kọ̀ọ́ àti àwọn tó ń
ṣe àwọn kóòsì. Ó ṣọ̀kan àwọn ẹ̀kọ́ tó ní ètò, àwọn ìdánilẹ́kọ̀ọ́ alábáṣepọ̀,
àwọn ìṣe ohùn àti ohun èlò àtúnyẹ̀wò, ó sì tún pèsè ohun èlò fún ṣíṣe àti
ṣíṣe àtúnṣe àwọn kóòsì èdè.

A ṣe é fún àwọn ènìyàn tó fẹ́ kọ́ èdè àti fún àwọn òǹkọ̀wé, olùkọ́ tàbí àwọn
olùlò míì tó fẹ́ dá kóòsì tiwọn sílẹ̀.

Fún àkótán àwòrán kúkúrú nípa bí QuisquisLingo ṣe ń ṣiṣẹ́, wo
QQL infographic.png, tó wà nínú package ìṣàfilọ́lẹ̀ náà.

Láti bẹ̀rẹ̀ QuisquisLingo, ṣiṣẹ́ QuisquisLingo.exe.

LÍLO PACKAGE
------------

Package yìí ní ìṣàfilọ́lẹ̀ QQL. Yọ gbogbo ZIP archive jáde kí o tó bẹ̀rẹ̀ rẹ̀,
kí o sì pa gbogbo àwọn file tí a pèsè àti folder data mọ́ pọ̀. Má ṣe pín,
gbé, pa tàbí tún orúkọ file EXE tàbí DLL kọ̀ọ̀kan ṣe.

ÀWỌN ÀYẸ̀WÒ ÌBẸ̀RẸ̀
-------------------

Kí ó tó bẹ̀rẹ̀, QuisquisLingo máa ń yẹ àwọn file package tó pọndandan,
ìbámu Windows àti Media Foundation wò. Àwọn àyẹ̀wò yìí kì í download tàbí
install software, kì í béèrè àṣẹ administrator, kì í yí registry tàbí Windows
padà.

Tí ó bá ṣeé tẹ̀síwájú lẹ́yìn ìṣòro kan, message kan péré pẹlu Continue anyway
àti Cancel ni yóò hàn. Continue anyway yóò gbìyànjú láti bẹ̀rẹ̀ QQL; Cancel yóò
pa á. Tí file program pàtàkì kan bá sọnù, message náà yóò fi Close hàn nítorí a
gbọ́dọ̀ tún download package náà, kí a sì yọ gbogbo rẹ̀ jáde.

Àtìlẹ́yìn Wine wà ní ipò Experimental. Tí Media Foundation kò bá sí lábẹ́ Wine,
ó lè dí ìbẹ̀rẹ̀ dúró tàbí mú kí àwọn iṣẹ́ ohùn àti media má ṣiṣẹ́.

MICROSOFT VISUAL C++ RUNTIME
----------------------------

Package pípé náà ní àwọn file runtime Microsoft Visual C++ x64 wọ̀nyí:

msvcp140.dll
vcruntime140.dll
vcruntime140_1.dll

Tí ọ̀kan bá sọnù, tún download package Windows QuisquisLingo pípé, kí o sì yọ
gbogbo rẹ̀ jáde. Lo àwọn orísun Microsoft osìṣẹ́ nìkan fún runtime installer,
má sì download file DLL kọ̀ọ̀kan láti website ẹlòmíràn láé.

Ìwífún osìṣẹ́ Microsoft:
https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist

MEDIA FOUNDATION
----------------

Àwọn edition Windows N lè nílò Microsoft Media Feature Pack fún iṣẹ́ ohùn àti
media. Media Feature Pack sábà máa ń wà lábẹ́ Windows Optional Features. Nínú
àwọn version Windows N kan, Media Feature Pack lè má sí ní Optional Features.
Nígbà bẹ́ẹ̀, download Media Feature Pack tó yẹ fún version Windows rẹ láti
website Microsoft.

Tún Windows bẹ̀rẹ̀ lẹ́yìn tí o bá install Media Feature Pack. QuisquisLingo kì
í download tàbí install rẹ̀ fúnra rẹ̀, kò sì ní yí àwọn setting system padà.

YÍYÍ Ọ̀RỌ̀ PADÀ SÍ OHÙN
-----------------------

QuisquisLingo ń lo àwọn ohùn ọ̀rọ̀ tí a install sí Windows. Àwọn èdè àti ohùn
tó wà sinmi lórí àwọn component èdè àti ohùn Windows tí a install sí computer.
Tí ohùn tó bá a mu kò bá sí, install component tó yẹ nípasẹ̀ àwọn setting
Windows.

Audio Settings > Test Voice ń sọ text tí o tẹ̀ wọlé nìkan, ó sì ń lo èdè ohùn
tí kóòsì tí a yàn ti ṣètò.

ÀWỌN LOG ÀTI ÌṢÀWÁRÍ
---------------------

Crash log àkọ́kọ́ wà níbí:

Documents\QuisquisLingo\Logs\quisquislingo_crash.log

Log àyẹ̀wò ìbẹ̀rẹ̀ wà níbí:

%LOCALAPPDATA%\QuisquisLingo\Logs\quisquislingo_launcher.log

Settings > Debug fi àwọn aṣàyàn ìṣàwárí hàn. Àwọn log náà dúró lórí computer
àdúgbò, a kì í sì upload wọn fúnra wọn.

YÍYANJU ÌṢÒRO
-------------

1. Yọ gbogbo ZIP archive jáde pátápátá.
2. Ṣiṣẹ́ QuisquisLingo.exe láti inú package tí a yọ jáde.
3. Tí a bá sọ pé runtime DLL kan sọnù, tún download package pípé, kí o sì yọ ọ́
   jáde kí o tó ronú nípa runtime installer osìṣẹ́ Microsoft.
4. Tí Media Feature Pack bá pọndandan, tẹ̀lé ìtọ́sọ́nà lókè, kí o sì tún Windows
   bẹ̀rẹ̀ lẹ́yìn install.
5. Tí QQL kò bá bẹ̀rẹ̀ síbẹ̀, pa gbogbo error message àti àwọn file log tó wà
   mọ́ fún ìrànlọ́wọ́.
