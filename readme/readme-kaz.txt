QuisquisLingo - Windows нұсқаулығы
=================================

QuisquisLingo — тіл үйренушілер мен курс жасаушыларға арналған тіл үйрену
қолданбасы. Ол құрылымды сабақтарды, интерактивті жаттығуларды, аудио
әрекеттерді және қайталау құралдарын біріктіреді, сондай-ақ тіл курстарын жасау
мен өңдеуге арналған құралдарды ұсынады.

Қолданба тіл үйренгісі келетін адамдарға да, өз курстарын жасағысы келетін
авторларға, мұғалімдерге және басқа пайдаланушыларға да арналған.

QuisquisLingo жұмысының қысқаша көрнекі шолуын қолданба пакетіне кіретін
QQL infographic.png файлынан қараңыз.

QuisquisLingo бағдарламасын бастау үшін QuisquisLingo.exe файлын іске қосыңыз.

ПАКЕТТІ ПАЙДАЛАНУ
-----------------

Бұл пакетте QQL қолданбасы бар. Бастамас бұрын ZIP мұрағатын толығымен шығарып,
берілген барлық файлдар мен data қалтасын бірге сақтаңыз. Жеке EXE немесе DLL
файлдарын таратпаңыз, жылжытпаңыз, жоймаңыз немесе қайта атамаңыз.

ІСКЕ ҚОСУ КЕЗІНДЕГІ ТЕКСЕРУЛЕР
------------------------------

Іске қоспас бұрын QuisquisLingo қажетті пакет файлдарын, Windows-пен
үйлесімділікті және Media Foundation қызметін тексереді. Бұл тексерулер ешқашан
бағдарламалық жасақтаманы жүктемейді немесе орнатпайды, әкімші құқықтарын
сұрамайды, registry немесе Windows жүйесін өзгертпейді.

Мәселеге қарамастан жалғастыруға болатын жағдайда Continue anyway және Cancel
түймелері бар бір хабар көрсетіледі. Continue anyway QQL қолданбасын іске қосуға
тырысады; Cancel оны жабады. Маңызды бағдарлама файлы жоқ болса, хабарда Close
ұсынылады, себебі пакетті қайта жүктеп, толығымен шығару қажет.

Wine қолдауы Experimental күйінде. Wine ортасында Media Foundation болмауы іске
қосуға кедергі келтіруі немесе аудио және медиа мүмкіндіктерінің жұмыс істемеуіне
әкелуі мүмкін.

MICROSOFT VISUAL C++ RUNTIME
----------------------------

Толық пакетте мына Microsoft Visual C++ x64 runtime файлдары бар:

msvcp140.dll
vcruntime140.dll
vcruntime140_1.dll

Олардың бірі жоқ болса, толық QuisquisLingo Windows пакетін қайта жүктеп,
толығымен шығарыңыз. Runtime installer үшін тек ресми Microsoft көздерін
пайдаланыңыз және жеке DLL файлдарын үшінші тарап веб-сайттарынан ешқашан
жүктемеңіз.

Microsoft компаниясының ресми ақпараты:
https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist

MEDIA FOUNDATION
----------------

Windows N шығарылымдары аудио және медиа функциялары үшін Microsoft Media
Feature Pack талап етуі мүмкін. Media Feature Pack әдетте Windows Optional
Features бөлімінде қолжетімді. Windows N жүйесінің кейбір нұсқаларында Media
Feature Pack Optional Features бөлімінде болмауы мүмкін. Мұндай жағдайда Windows
нұсқаңызға сәйкес Media Feature Pack пакетін Microsoft веб-сайтынан жүктеп алыңыз.

Media Feature Pack орнатылғаннан кейін Windows жүйесін қайта іске қосыңыз.
QuisquisLingo оны автоматты түрде жүктемейді немесе орнатпайды және жүйе
параметрлерін өзгертпейді.

МӘТІНДІ СӨЙЛЕУГЕ ТҮРЛЕНДІРУ
---------------------------

QuisquisLingo Windows жүйесінде орнатылған сөйлеу дауыстарын пайдаланады.
Қолжетімді тілдер мен дауыстар компьютерде орнатылған Windows тіл және дауыс
құрамдастарына байланысты. Үйлесімді дауыс болмаса, тиісті құрамдасты Windows
параметрлері арқылы орнатыңыз.

Audio Settings > Test Voice тек енгізген мәтініңізді дыбыстап, таңдалған курста
бапталған дауыс тілін пайдаланады.

ЖУРНАЛДАР ЖӘНЕ ДИАГНОСТИКА
--------------------------

Негізгі crash log мына жерде сақталады:

Documents\QuisquisLingo\Logs\quisquislingo_crash.log

Іске қосу тексеруінің log файлы мына жерде сақталады:

%LOCALAPPDATA%\QuisquisLingo\Logs\quisquislingo_launcher.log

Settings > Debug диагностика параметрлерін көрсетеді. Log файлдары жергілікті
компьютерде қалып, автоматты түрде жүктеп жіберілмейді.

АҚАУЛАРДЫ ЖОЮ
-------------

1. Бүкіл ZIP мұрағатын толығымен шығарыңыз.
2. Шығарылған пакеттен QuisquisLingo.exe файлын іске қосыңыз.
3. Runtime DLL жоқ деп хабарланса, ресми Microsoft runtime installer қолдануды
   қарастырмас бұрын толық пакетті қайта жүктеп, шығарыңыз.
4. Media Feature Pack қажет болса, жоғарыдағы нұсқауларды орындап, орнатқаннан
   кейін Windows жүйесін қайта іске қосыңыз.
5. QQL әлі іске қосылмаса, қолдау алу үшін толық қате хабарын және қолжетімді log
   файлдарын сақтаңыз.
