QuisquisLingo - Windows-ის გზამკვლევი
====================================

QuisquisLingo არის ენების შემსწავლელი აპლიკაცია მოსწავლეებისა და კურსების
შემქმნელებისთვის. ის აერთიანებს სტრუქტურირებულ გაკვეთილებს, ინტერაქტიურ
სავარჯიშოებს, აუდიო აქტივობებსა და გამეორების ხელსაწყოებს, ამასთანავე კი
უზრუნველყოფს ენის კურსების შექმნისა და რედაქტირების ხელსაწყოებს.

ის განკუთვნილია როგორც ენის სწავლის მსურველთათვის, ისე ავტორებისთვის,
მასწავლებლებისა და სხვა მომხმარებლებისთვის, რომლებსაც საკუთარი კურსების შექმნა
სურთ.

QuisquisLingo-ის მუშაობის სწრაფი ვიზუალური მიმოხილვისთვის იხილეთ აპლიკაციის
პაკეტში შეტანილი QQL infographic.png.

QuisquisLingo-ის გასაშვებად გაუშვით QuisquisLingo.exe.

პაკეტის გამოყენება
------------------

ეს პაკეტი შეიცავს QQL აპლიკაციას. გაშვებამდე სრულად ამოიღეთ ZIP არქივის შიგთავსი
და ყველა მოწოდებული ფაილი და data საქაღალდე ერთად შეინახეთ. ცალკეული EXE ან DLL
ფაილები არ გაავრცელოთ, გადაიტანოთ, წაშალოთ ან გადაარქვათ.

გაშვების შემოწმებები
--------------------

გაშვებამდე QuisquisLingo ამოწმებს პაკეტის აუცილებელ ფაილებს, Windows-თან
თავსებადობასა და Media Foundation-ს. ეს შემოწმებები არასდროს ჩამოტვირთავს ან
დააყენებს პროგრამულ უზრუნველყოფას, არ მოითხოვს ადმინისტრატორის უფლებებს, არ
შეცვლის registry-ს ან Windows-ს.

თუ პრობლემის მიუხედავად გაგრძელება შესაძლებელია, გამოჩნდება ერთი შეტყობინება
Continue anyway და Cancel არჩევანით. Continue anyway ცდილობს QQL-ის გაშვებას;
Cancel მას ხურავს. თუ პროგრამის აუცილებელი ფაილი აკლია, შეტყობინება გთავაზობთ
Close-ს, რადგან პაკეტი ხელახლა უნდა ჩამოიტვირთოს და სრულად გაიხსნას.

Wine-ის მხარდაჭერა Experimental არის. Wine-ში Media Foundation-ის არარსებობამ
შეიძლება ხელი შეუშალოს გაშვებას ან აუდიო და მედია ფუნქციების მუშაობას.

MICROSOFT VISUAL C++ RUNTIME
----------------------------

სრული პაკეტი შეიცავს Microsoft Visual C++ x64-ის შემდეგ runtime ფაილებს:

msvcp140.dll
vcruntime140.dll
vcruntime140_1.dll

თუ რომელიმე მათგანი აკლია, ხელახლა ჩამოტვირთეთ QuisquisLingo-ის სრული Windows
პაკეტი და მთლიანად გახსენით. Runtime installer-ისთვის გამოიყენეთ მხოლოდ
Microsoft-ის ოფიციალური წყაროები და არასდროს ჩამოტვირთოთ ცალკეული DLL ფაილები
მესამე მხარის ვებსაიტებიდან.

Microsoft-ის ოფიციალური ინფორმაცია:
https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist

MEDIA FOUNDATION
----------------

Windows N გამოცემებს აუდიო და მედია ფუნქციებისთვის შეიძლება Microsoft Media
Feature Pack დასჭირდეთ. Media Feature Pack ჩვეულებრივ ხელმისაწვდომია Windows
Optional Features-ში. Windows N-ის ზოგიერთ ვერსიაში Media Feature Pack შეიძლება
Optional Features-ში არ იყოს. ასეთ შემთხვევაში Microsoft-ის ვებსაიტიდან
ჩამოტვირთეთ თქვენი Windows-ის ვერსიისთვის შესაფერისი Media Feature Pack.

Media Feature Pack-ის დაყენების შემდეგ გადატვირთეთ Windows. QuisquisLingo მას
ავტომატურად არ ჩამოტვირთავს ან დააყენებს და სისტემის პარამეტრებს არ ცვლის.

ტექსტის მეტყველებად გარდაქმნა
----------------------------

QuisquisLingo იყენებს Windows-ში დაყენებულ სამეტყველო ხმებს. ხელმისაწვდომი ენები
და ხმები დამოკიდებულია კომპიუტერში დაყენებულ Windows-ის ენისა და ხმის
კომპონენტებზე. თუ თავსებადი ხმა არ არის, Windows-ის პარამეტრებიდან დააყენეთ
შესაბამისი კომპონენტი.

Audio Settings > Test Voice წარმოთქვამს მხოლოდ თქვენ მიერ შეყვანილ ტექსტს და
იყენებს არჩეული კურსისთვის გამართულ ხმის ენას.

ჟურნალები და დიაგნოსტიკა
------------------------

მთავარი crash log ინახება აქ:

Documents\QuisquisLingo\Logs\quisquislingo_crash.log

გაშვების შემოწმების log ინახება აქ:

%LOCALAPPDATA%\QuisquisLingo\Logs\quisquislingo_launcher.log

Settings > Debug აჩვენებს დიაგნოსტიკის ვარიანტებს. Log ფაილები რჩება ადგილობრივ
კომპიუტერში და ავტომატურად არ იტვირთება.

პრობლემების მოგვარება
---------------------

1. სრულად ამოიღეთ მთელი ZIP არქივის შიგთავსი.
2. გახსნილი პაკეტიდან გაუშვით QuisquisLingo.exe.
3. თუ შეტყობინება მიუთითებს, რომ runtime DLL აკლია, Microsoft-ის ოფიციალური
   runtime installer-ის განხილვამდე ხელახლა ჩამოტვირთეთ და გახსენით სრული პაკეტი.
4. თუ Media Feature Pack საჭიროა, მიჰყევით ზემოთ მოცემულ მითითებებს და დაყენების
   შემდეგ გადატვირთეთ Windows.
5. თუ QQL კვლავ არ ირთვება, მხარდაჭერისთვის შეინახეთ შეცდომის სრული შეტყობინება
   და ხელმისაწვდომი log ფაილები.
