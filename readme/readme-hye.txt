QuisquisLingo - Windows ուղեցույց
================================

QuisquisLingo-ն լեզուներ սովորելու հավելված է սովորողների և դասընթացներ
ստեղծողների համար։ Այն համատեղում է կառուցվածքային դասեր, փոխազդեցիկ
վարժություններ, ձայնային գործողություններ և կրկնության գործիքներ, ինչպես նաև
տրամադրում է լեզվի դասընթացներ ստեղծելու և խմբագրելու գործիքներ։

Այն նախատեսված է թե՛ լեզու սովորել ցանկացողների, թե՛ իրենց դասընթացները ստեղծել
ցանկացող հեղինակների, ուսուցիչների և այլ օգտատերերի համար։

QuisquisLingo-ի աշխատանքի արագ տեսողական ակնարկի համար դիտեք հավելվածի փաթեթում
ներառված QQL infographic.png ֆայլը։

QuisquisLingo-ն գործարկելու համար աշխատեցրեք QuisquisLingo.exe ֆայլը։

ՓԱԹԵԹԻ ՕԳՏԱԳՈՐԾՈՒՄԸ
--------------------

Այս փաթեթը պարունակում է QQL հավելվածը։ Գործարկելուց առաջ ամբողջությամբ բացեք
ZIP արխիվը և բոլոր տրամադրված ֆայլերն ու data պանակը միասին պահեք։ Առանձին EXE
կամ DLL ֆայլեր մի տարածեք, տեղափոխեք, ջնջեք կամ վերանվանեք։

ԳՈՐԾԱՐԿՄԱՆ ՍՏՈՒԳՈՒՄՆԵՐ
-----------------------

Գործարկումից առաջ QuisquisLingo-ն ստուգում է փաթեթի անհրաժեշտ ֆայլերը, Windows-ի
համատեղելիությունը և Media Foundation-ը։ Այս ստուգումները երբեք ծրագրակազմ չեն
ներբեռնում կամ տեղադրում, վարչարարի իրավունք չեն խնդրում, registry-ն կամ
Windows-ը չեն փոխում։

Եթե խնդրից հետո հնարավոր է շարունակել, ցուցադրվում է մեկ հաղորդագրություն՝
Continue anyway և Cancel տարբերակներով։ Continue anyway-ը փորձում է գործարկել
QQL-ը, իսկ Cancel-ը փակում է այն։ Եթե բացակայում է ծրագրի անհրաժեշտ ֆայլ, ապա
հաղորդագրությունն առաջարկում է Close, քանի որ փաթեթը պետք է կրկին ներբեռնել և
ամբողջությամբ բացել։

Wine-ի աջակցությունը Experimental է։ Wine-ում Media Foundation-ի բացակայությունը
կարող է խանգարել գործարկմանը կամ ձայնային և մեդիա գործառույթների աշխատանքին։

MICROSOFT VISUAL C++ RUNTIME
----------------------------

Ամբողջական փաթեթը ներառում է Microsoft Visual C++ x64-ի հետևյալ runtime ֆայլերը․

msvcp140.dll
vcruntime140.dll
vcruntime140_1.dll

Եթե դրանցից մեկը բացակայում է, կրկին ներբեռնեք QuisquisLingo-ի ամբողջական
Windows փաթեթը և այն ամբողջությամբ բացեք։ Runtime installer-ի համար օգտագործեք
միայն Microsoft-ի պաշտոնական աղբյուրները և երբեք առանձին DLL ֆայլեր մի
ներբեռնեք երրորդ կողմի կայքերից։

Microsoft-ի պաշտոնական տեղեկություններ․
https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist

MEDIA FOUNDATION
----------------

Windows N թողարկումներում ձայնային և մեդիա գործառույթների համար կարող է պահանջվել
Microsoft Media Feature Pack։ Media Feature Pack-ը սովորաբար հասանելի է Windows
Optional Features-ում։ Windows N-ի որոշ տարբերակներում Media Feature Pack-ը
կարող է հասանելի չլինել Optional Features-ում։ Այդ դեպքում Microsoft-ի կայքից
ներբեռնեք Windows-ի ձեր տարբերակին համապատասխան Media Feature Pack-ը։

Media Feature Pack-ը տեղադրելուց հետո վերագործարկեք Windows-ը։ QuisquisLingo-ն
այն ինքնաբերաբար չի ներբեռնում կամ տեղադրում և չի փոխում համակարգի կարգավորումները։

ՏԵՔՍՏԻՑ ԽՈՍՔ
-------------

QuisquisLingo-ն օգտագործում է Windows-ում տեղադրված խոսքային ձայները։ Հասանելի
լեզուներն ու ձայները կախված են համակարգչում տեղադրված Windows-ի լեզվային և
ձայնային բաղադրիչներից։ Եթե համատեղելի ձայն չկա, Windows-ի կարգավորումներից
տեղադրեք համապատասխան բաղադրիչը։

Audio Settings > Test Voice-ը արտասանում է միայն ձեր մուտքագրած տեքստը և
օգտագործում է ընտրված դասընթացում կազմաձևված ձայնի լեզուն։

ՄԱՏՅԱՆՆԵՐ ԵՎ ԱԽՏՈՐՈՇՈՒՄ
-----------------------

Հիմնական crash log-ը պահվում է այստեղ․

Documents\QuisquisLingo\Logs\quisquislingo_crash.log

Գործարկման ստուգման log-ը պահվում է այստեղ․

%LOCALAPPDATA%\QuisquisLingo\Logs\quisquislingo_launcher.log

Settings > Debug-ը ցուցադրում է ախտորոշման տարբերակները։ Log-երը մնում են
տեղային համակարգչում և ինքնաբերաբար չեն վերբեռնվում։

ԽՆԴԻՐՆԵՐԻ ԼՈՒԾՈՒՄ
------------------

1. Ամբողջությամբ բացեք ամբողջ ZIP արխիվը։
2. Բացված փաթեթից աշխատեցրեք QuisquisLingo.exe-ը։
3. Եթե հաղորդվում է runtime DLL-ի բացակայության մասին, կրկին ներբեռնեք և բացեք
   ամբողջական փաթեթը՝ նախքան Microsoft-ի պաշտոնական runtime installer դիտարկելը։
4. Եթե Media Feature Pack է անհրաժեշտ, հետևեք վերը նշված ցուցումներին և
   տեղադրումից հետո վերագործարկեք Windows-ը։
5. Եթե QQL-ը դեռ չի գործարկվում, աջակցության համար պահեք սխալի ամբողջական
   հաղորդագրությունը և հասանելի log ֆայլերը։
