QuisquisLingo - Windows வழிகாட்டி
================================

QuisquisLingo என்பது மொழி கற்பவர்களுக்கும் பாடநெறி உருவாக்குபவர்களுக்கும் உரிய
மொழிக் கற்றல் பயன்பாடாகும். இது கட்டமைக்கப்பட்ட பாடங்கள், ஊடாடும் பயிற்சிகள்,
ஒலி செயல்பாடுகள் மற்றும் மீள்பார்வைக் கருவிகளை ஒருங்கிணைப்பதுடன், மொழிப்
பாடநெறிகளை உருவாக்கவும் திருத்தவும் கருவிகளை வழங்குகிறது.

ஒரு மொழியைக் கற்க விரும்புபவர்களுக்கும், தங்கள் சொந்தப் பாடநெறிகளை உருவாக்க
விரும்பும் ஆசிரியர்கள், கற்பிப்பவர்கள் மற்றும் பிற பயனர்களுக்கும் இது
வடிவமைக்கப்பட்டுள்ளது.

QuisquisLingo எவ்வாறு செயல்படுகிறது என்பதற்கான விரைவான காட்சி அறிமுகத்திற்கு,
பயன்பாட்டுத் தொகுப்பில் சேர்க்கப்பட்டுள்ள QQL infographic.png கோப்பைப் பார்க்கவும்.

QuisquisLingo-ஐத் தொடங்க QuisquisLingo.exe-ஐ இயக்கவும்.

தொகுப்பைப் பயன்படுத்துதல்
------------------------

இந்தத் தொகுப்பில் QQL பயன்பாடு உள்ளது. தொடங்குவதற்கு முன் முழு ZIP காப்பகத்தையும்
பிரித்தெடுத்து, வழங்கப்பட்ட எல்லாக் கோப்புகளையும் data கோப்புறையையும் ஒன்றாக
வைத்திருக்கவும். தனிப்பட்ட EXE அல்லது DLL கோப்புகளைப் பகிரவோ, நகர்த்தவோ, நீக்கவோ,
மறுபெயரிடவோ வேண்டாம்.

தொடக்கச் சோதனைகள்
-----------------

தொடங்குவதற்கு முன், QuisquisLingo தேவையான தொகுப்புக் கோப்புகள், Windows இணக்கத்தன்மை
மற்றும் Media Foundation ஆகியவற்றைச் சோதிக்கிறது. இந்தச் சோதனைகள் மென்பொருளைப்
பதிவிறக்கவோ நிறுவவோ, நிர்வாகி அனுமதியைக் கோரவோ, registry அல்லது Windows-ஐ
மாற்றவோ மாட்டா.

ஒரு சிக்கலுக்குப் பின்னரும் தொடர முடிந்தால், Continue anyway மற்றும் Cancel உள்ள
ஒரே செய்தி தோன்றும். Continue anyway QQL-ஐத் தொடங்க முயலும்; Cancel அதை மூடும்.
அத்தியாவசிய நிரல் கோப்பு இல்லை என்றால், தொகுப்பை மீண்டும் பதிவிறக்கி முழுமையாகப்
பிரித்தெடுக்க வேண்டியதால் செய்தி Close என்பதை வழங்கும்.

Wine ஆதரவு Experimental நிலையில் உள்ளது. Wine-ல் Media Foundation இல்லாதது
தொடக்கத்தைத் தடுக்கலாம் அல்லது ஒலி மற்றும் ஊடக அம்சங்கள் செயல்படாமல் செய்யலாம்.

MICROSOFT VISUAL C++ RUNTIME
----------------------------

முழுத் தொகுப்பில் பின்வரும் Microsoft Visual C++ x64 runtime கோப்புகள் உள்ளன:

msvcp140.dll
vcruntime140.dll
vcruntime140_1.dll

இவற்றில் ஒன்று இல்லை என்றால், முழு QuisquisLingo Windows தொகுப்பையும் மீண்டும்
பதிவிறக்கி முழுமையாகப் பிரித்தெடுக்கவும். Runtime installer-க்கு Microsoft-ன்
அதிகாரப்பூர்வ மூலங்களை மட்டும் பயன்படுத்தவும்; மூன்றாம் தரப்பு இணையதளங்களிலிருந்து
தனித்தனி DLL கோப்புகளை ஒருபோதும் பதிவிறக்க வேண்டாம்.

Microsoft-ன் அதிகாரப்பூர்வ தகவல்:
https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist

MEDIA FOUNDATION
----------------

Windows N பதிப்புகளில் ஒலி மற்றும் ஊடகச் செயல்பாடுகளுக்கு Microsoft Media Feature
Pack தேவைப்படலாம். Media Feature Pack பொதுவாக Windows Optional Features-ல்
கிடைக்கும். Windows N-ன் சில பதிப்புகளில் Media Feature Pack Optional Features-ல்
கிடைக்காமல் இருக்கலாம். அப்போது உங்கள் Windows பதிப்புக்கு ஏற்ற Media Feature
Pack-ஐ Microsoft இணையதளத்திலிருந்து பதிவிறக்கவும்.

Media Feature Pack-ஐ நிறுவிய பிறகு Windows-ஐ மறுதொடக்கம் செய்யவும். QuisquisLingo
அதைத் தானாகப் பதிவிறக்கவோ நிறுவவோ செய்யாது; கணினி அமைப்புகளையும் மாற்றாது.

உரையைப் பேச்சாக மாற்றுதல்
------------------------

QuisquisLingo Windows-ல் நிறுவப்பட்ட பேச்சுக் குரல்களைப் பயன்படுத்துகிறது. கிடைக்கும்
மொழிகளும் குரல்களும் கணினியில் நிறுவப்பட்ட Windows மொழி மற்றும் குரல் கூறுகளைப்
பொறுத்தவை. இணக்கமான குரல் இல்லாவிட்டால், Windows அமைப்புகள் மூலம் பொருத்தமான கூறை
நிறுவவும்.

Audio Settings > Test Voice நீங்கள் உள்ளிட்ட உரையை மட்டுமே பேசும்; தேர்ந்தெடுத்த
பாடநெறியில் அமைக்கப்பட்ட குரல் மொழியைப் பயன்படுத்தும்.

பதிவுகள் மற்றும் கண்டறிதல்
--------------------------

முதன்மை crash log இங்கே சேமிக்கப்படும்:

Documents\QuisquisLingo\Logs\quisquislingo_crash.log

தொடக்கச் சோதனையின் log இங்கே சேமிக்கப்படும்:

%LOCALAPPDATA%\QuisquisLingo\Logs\quisquislingo_launcher.log

Settings > Debug கண்டறிதல் விருப்பங்களைக் காட்டும். Log கோப்புகள் உள்ளூர்
கணினியிலேயே இருக்கும்; தானாகப் பதிவேற்றப்படாது.

சிக்கல் தீர்வு
-------------

1. முழு ZIP காப்பகத்தையும் முற்றிலும் பிரித்தெடுக்கவும்.
2. பிரித்தெடுத்த தொகுப்பிலிருந்து QuisquisLingo.exe-ஐ இயக்கவும்.
3. Runtime DLL இல்லை என்று தெரிவிக்கப்பட்டால், அதிகாரப்பூர்வ Microsoft runtime
   installer-ஐப் பரிசீலிப்பதற்கு முன் முழுத் தொகுப்பையும் மீண்டும் பதிவிறக்கிப்
   பிரித்தெடுக்கவும்.
4. Media Feature Pack தேவைப்பட்டால், மேலுள்ள வழிகாட்டுதலைப் பின்பற்றி நிறுவிய
   பிறகு Windows-ஐ மறுதொடக்கம் செய்யவும்.
5. QQL இன்னும் தொடங்கவில்லை என்றால், உதவிக்காக முழுப் பிழைச் செய்தியையும் கிடைக்கும்
   log கோப்புகளையும் வைத்திருக்கவும்.
