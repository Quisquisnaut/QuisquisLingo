QuisquisLingo - Водич за Windows
================================

QuisquisLingo је апликација за учење језика намењена ученицима и ауторима
курсева. Обједињује структуриране лекције, интерактивне вежбе, звучне активности
и алате за понављање, а пружа и алате за прављење и уређивање језичких курсева.

Намењена је људима који желе да уче језик, као и ауторима, наставницима и другим
корисницима који желе да направе сопствене курсеве.

За брз визуелни преглед рада апликације QuisquisLingo погледајте
QQL infographic.png, која је приложена у пакету апликације.

Да бисте покренули QuisquisLingo, извршите QuisquisLingo.exe.

КОРИШЋЕЊЕ ПАКЕТА
----------------

Овај пакет садржи апликацију QQL. Пре покретања у потпуности распакујте ZIP
архиву и држите све приложене датотеке и фасциклу data заједно. Немојте засебно
делити, премештати, брисати или преименовати EXE или DLL датотеке.

ПРОВЕРЕ ПРИ ПОКРЕТАЊУ
---------------------

Пре покретања QuisquisLingo проверава потребне датотеке пакета, компатибилност
са системом Windows и Media Foundation. Ове провере никада не преузимају нити
инсталирају софтвер, не траже администраторска овлашћења, не мењају registry ни
Windows.

Ако је упркос проблему могуће наставити, приказује се једна порука са Continue
anyway и Cancel. Continue anyway покушава да покрене QQL; Cancel га затвара. Ако
недостаје неопходна програмска датотека, порука нуди Close јер пакет мора поново
да се преузме и потпуно распакује.

Подршка за Wine је Experimental. Ако Media Foundation недостаје у окружењу Wine,
покретање може бити онемогућено или звучне и медијске функције можда неће радити.

MICROSOFT VISUAL C++ RUNTIME
----------------------------

Потпуни пакет садржи следеће runtime датотеке Microsoft Visual C++ x64:

msvcp140.dll
vcruntime140.dll
vcruntime140_1.dll

Ако нека недостаје, поново преузмите потпуни пакет QuisquisLingo за Windows и
распакујте га у целости. За runtime installer користите само званичне Microsoft
изворе и никада не преузимајте појединачне DLL датотеке са веб-сајтова трећих
страна.

Званичне информације компаније Microsoft:
https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist

MEDIA FOUNDATION
----------------

Издањима Windows N може бити потребан Microsoft Media Feature Pack за звучне и
медијске функције. Media Feature Pack је обично доступан у одељку Windows
Optional Features. У неким верзијама система Windows N Media Feature Pack можда
није доступан у Optional Features. У том случају са веб-сајта компаније Microsoft
преузмите Media Feature Pack који одговара вашој верзији система Windows.

После инсталације пакета Media Feature Pack поново покрените Windows.
QuisquisLingo га не преузима нити инсталира аутоматски и не мења системска
подешавања.

ПРЕТВАРАЊЕ ТЕКСТА У ГОВОР
--------------------------

QuisquisLingo користи гласове инсталиране у систему Windows. Доступни језици и
гласови зависе од језичких и гласовних компонената система Windows инсталираних
на рачунару. Ако нема компатибилног гласа, инсталирајте одговарајућу компоненту
кроз подешавања система Windows.

Audio Settings > Test Voice изговара само текст који унесете и користи језик
гласа подешен за изабрани курс.

ЕВИДЕНЦИЈЕ И ДИЈАГНОСТИКА
-------------------------

Главни crash log чува се овде:

Documents\QuisquisLingo\Logs\quisquislingo_crash.log

Log провере при покретању чува се овде:

%LOCALAPPDATA%\QuisquisLingo\Logs\quisquislingo_launcher.log

Settings > Debug приказује дијагностичке могућности. Log датотеке остају на
локалном рачунару и не отпремају се аутоматски.

РЕШАВАЊЕ ПРОБЛЕМА
-----------------

1. У потпуности распакујте целу ZIP архиву.
2. Покрените QuisquisLingo.exe из распакованог пакета.
3. Ако се пријави да недостаје runtime DLL, поново преузмите и распакујте цео
   пакет пре него што размотрите званични Microsoft runtime installer.
4. Ако је потребан Media Feature Pack, пратите упутства изнад и после
   инсталације поново покрените Windows.
5. Ако се QQL и даље не покреће, сачувајте целу поруку о грешци и доступне log
   датотеке за подршку.
