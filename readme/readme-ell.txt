QuisquisLingo - Οδηγός για Windows
=================================

Το QuisquisLingo είναι μια εφαρμογή εκμάθησης γλωσσών για μαθητές και
δημιουργούς μαθημάτων. Συνδυάζει δομημένα μαθήματα, διαδραστικές ασκήσεις,
δραστηριότητες ήχου και εργαλεία επανάληψης, ενώ παρέχει επίσης εργαλεία για τη
δημιουργία και την επεξεργασία γλωσσικών μαθημάτων.

Έχει σχεδιαστεί τόσο για ανθρώπους που θέλουν να μάθουν μια γλώσσα όσο και για
συγγραφείς, εκπαιδευτικούς ή άλλους χρήστες που θέλουν να δημιουργήσουν τα δικά
τους μαθήματα.

Για μια γρήγορη οπτική επισκόπηση του τρόπου λειτουργίας του QuisquisLingo,
δείτε το QQL infographic.png, το οποίο περιλαμβάνεται στο πακέτο της εφαρμογής.

Για να ξεκινήσετε το QuisquisLingo, εκτελέστε το QuisquisLingo.exe.

ΧΡΗΣΗ ΤΟΥ ΠΑΚΕΤΟΥ
-----------------

Αυτό το πακέτο περιέχει την εφαρμογή QQL. Αποσυμπιέστε ολόκληρο το αρχείο ZIP
πριν την εκκινήσετε και διατηρήστε μαζί όλα τα παρεχόμενα αρχεία και τον φάκελο
data. Μη διανέμετε, μετακινείτε, διαγράφετε ή μετονομάζετε μεμονωμένα αρχεία EXE
ή DLL.

ΕΛΕΓΧΟΙ ΕΚΚΙΝΗΣΗΣ
-----------------

Πριν από την εκκίνηση, το QuisquisLingo ελέγχει τα απαιτούμενα αρχεία του
πακέτου, τη συμβατότητα με τα Windows και το Media Foundation. Αυτοί οι έλεγχοι
δεν κάνουν ποτέ λήψη ή εγκατάσταση λογισμικού, δεν ζητούν δικαιώματα διαχειριστή,
δεν αλλάζουν το registry ούτε τροποποιούν τα Windows.

Αν ένα πρόβλημα επιτρέπει τη συνέχιση, εμφανίζεται ένα μήνυμα με Continue anyway
και Cancel. Το Continue anyway επιχειρεί να ξεκινήσει το QQL, ενώ το Cancel το
κλείνει. Αν λείπει ένα απαραίτητο αρχείο προγράμματος, το μήνυμα προσφέρει Close,
επειδή πρέπει να γίνει ξανά λήψη και πλήρης αποσυμπίεση του πακέτου.

Η υποστήριξη του Wine είναι Experimental. Η έλλειψη του Media Foundation στο
Wine μπορεί να εμποδίσει την εκκίνηση ή τη λειτουργία των δυνατοτήτων ήχου και
πολυμέσων.

MICROSOFT VISUAL C++ RUNTIME
----------------------------

Το πλήρες πακέτο περιλαμβάνει τα ακόλουθα αρχεία runtime Microsoft Visual C++ x64:

msvcp140.dll
vcruntime140.dll
vcruntime140_1.dll

Αν λείπει κάποιο από αυτά, κατεβάστε ξανά το πλήρες πακέτο QuisquisLingo για
Windows και αποσυμπιέστε το πλήρως. Χρησιμοποιείτε μόνο επίσημες πηγές της
Microsoft για runtime installer και μην κατεβάζετε ποτέ μεμονωμένα αρχεία DLL
από ιστοτόπους τρίτων.

Επίσημες πληροφορίες της Microsoft:
https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist

MEDIA FOUNDATION
----------------

Οι εκδόσεις Windows N ενδέχεται να χρειάζονται το Microsoft Media Feature Pack
για λειτουργίες ήχου και πολυμέσων. Το Media Feature Pack διατίθεται συνήθως στο
Windows Optional Features. Σε ορισμένες εκδόσεις των Windows N, το Media Feature
Pack ενδέχεται να μην είναι διαθέσιμο στο Optional Features. Σε αυτή την
περίπτωση, κατεβάστε από τον ιστότοπο της Microsoft το κατάλληλο Media Feature
Pack για τη δική σας έκδοση των Windows.

Επανεκκινήστε τα Windows μετά την εγκατάσταση του Media Feature Pack. Το
QuisquisLingo δεν το κατεβάζει ή εγκαθιστά αυτόματα και δεν αλλάζει τις ρυθμίσεις
του συστήματος.

ΜΕΤΑΤΡΟΠΗ ΚΕΙΜΕΝΟΥ ΣΕ ΟΜΙΛΙΑ
----------------------------

Το QuisquisLingo χρησιμοποιεί τις φωνές ομιλίας που είναι εγκατεστημένες στα
Windows. Οι διαθέσιμες γλώσσες και φωνές εξαρτώνται από τα στοιχεία γλώσσας και
φωνής των Windows που είναι εγκατεστημένα στον υπολογιστή. Αν δεν υπάρχει
συμβατή φωνή, εγκαταστήστε το κατάλληλο στοιχείο από τις ρυθμίσεις των Windows.

Το Audio Settings > Test Voice εκφωνεί μόνο το κείμενο που εισάγετε και
χρησιμοποιεί τη γλώσσα φωνής που έχει ρυθμιστεί από το επιλεγμένο μάθημα.

ΑΡΧΕΙΑ ΚΑΤΑΓΡΑΦΗΣ ΚΑΙ ΔΙΑΓΝΩΣΤΙΚΑ
---------------------------------

Το κύριο crash log αποθηκεύεται εδώ:

Documents\QuisquisLingo\Logs\quisquislingo_crash.log

Το log του ελέγχου εκκίνησης αποθηκεύεται εδώ:

%LOCALAPPDATA%\QuisquisLingo\Logs\quisquislingo_launcher.log

Το Settings > Debug εμφανίζει διαγνωστικές επιλογές. Τα log παραμένουν στον
τοπικό υπολογιστή και δεν αποστέλλονται αυτόματα.

ΑΝΤΙΜΕΤΩΠΙΣΗ ΠΡΟΒΛΗΜΑΤΩΝ
------------------------

1. Αποσυμπιέστε πλήρως ολόκληρο το αρχείο ZIP.
2. Εκτελέστε το QuisquisLingo.exe από το αποσυμπιεσμένο πακέτο.
3. Αν αναφερθεί ότι λείπει runtime DLL, κατεβάστε και αποσυμπιέστε ξανά το πλήρες
   πακέτο πριν εξετάσετε το ενδεχόμενο επίσημου Microsoft runtime installer.
4. Αν απαιτείται Media Feature Pack, ακολουθήστε τις παραπάνω οδηγίες και
   επανεκκινήστε τα Windows μετά την εγκατάσταση.
5. Αν το QQL εξακολουθεί να μην ξεκινά, κρατήστε ολόκληρο το μήνυμα σφάλματος και
   τα διαθέσιμα αρχεία log για υποστήριξη.
