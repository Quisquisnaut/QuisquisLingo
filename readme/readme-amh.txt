QuisquisLingo - የWindows መመሪያ
=============================

QuisquisLingo ለቋንቋ ተማሪዎችና ለኮርስ ፈጣሪዎች የተዘጋጀ የቋንቋ መማሪያ
መተግበሪያ ነው። የተዋቀሩ ትምህርቶችን፣ ተግባቦታዊ ልምምዶችን፣ የድምፅ
እንቅስቃሴዎችንና የክለሳ መሳሪያዎችን ያጣምራል፤ የቋንቋ ኮርሶችን ለመፍጠርና
ለማርትዕም መሳሪያዎችን ይሰጣል።

ቋንቋ ለመማር ለሚፈልጉ ሰዎች እንዲሁም የራሳቸውን ኮርስ ለመስራት ለሚፈልጉ
ደራሲዎች፣ መምህራንና ሌሎች ተጠቃሚዎች ተዘጋጅቷል።

QuisquisLingo እንዴት እንደሚሰራ ፈጣን ምስላዊ መግለጫ ለማየት በመተግበሪያው
ፓኬጅ ውስጥ የተካተተውን QQL infographic.png ይመልከቱ።

QuisquisLingoን ለማስጀመር QuisquisLingo.exeን ያስኪዱ።

ፓኬጁን መጠቀም
--------------

ይህ ፓኬጅ QQL መተግበሪያን ይዟል። ከማስጀመርዎ በፊት ሙሉውን ZIP ማህደር
ያውጡ፣ የቀረቡትን ፋይሎች በሙሉና data አቃፊውን አንድ ላይ ያቆዩ። ነጠላ EXE
ወይም DLL ፋይሎችን አያሰራጩ፣ አያንቀሳቅሱ፣ አይሰርዙ ወይም ስማቸውን አይቀይሩ።

የማስጀመሪያ ምርመራዎች
--------------------

QuisquisLingo ከመጀመሩ በፊት አስፈላጊ የፓኬጅ ፋይሎችን፣ ከWindows ጋር ያለውን
ተኳኋኝነትና Media Foundationን ይመረምራል። እነዚህ ምርመራዎች ሶፍትዌርን
አያወርዱም ወይም አይጭኑም፣ የአስተዳዳሪ ፈቃድ አይጠይቁም፣ registryን ወይም
Windowsን አይቀይሩም።

ችግር ቢኖርም መቀጠል ከተቻለ Continue anyway እና Cancel ያሉበት አንድ መልዕክት
ይታያል። Continue anyway QQLን ለማስጀመር ይሞክራል፤ Cancel ይዘጋዋል። አስፈላጊ
የፕሮግራም ፋይል ከጎደለ ፓኬጁን እንደገና ማውረድና ሙሉ በሙሉ ማውጣት ስለሚያስፈልግ
መልዕክቱ Closeን ያሳያል።

የWine ድጋፍ Experimental ነው። በWine ውስጥ Media Foundation አለመኖሩ
መጀመርን ሊከለክል ወይም የድምፅና ሚዲያ ባህሪያት እንዳይሰሩ ሊያደርግ ይችላል።

MICROSOFT VISUAL C++ RUNTIME
----------------------------

ሙሉው ፓኬጅ የሚከተሉትን Microsoft Visual C++ x64 runtime ፋይሎች ያካትታል፦

msvcp140.dll
vcruntime140.dll
vcruntime140_1.dll

አንዱ ከጎደለ ሙሉውን የQuisquisLingo Windows ፓኬጅ እንደገና አውርደው ሙሉ በሙሉ
ያውጡት። ለruntime installer ኦፊሴላዊ የMicrosoft ምንጮችን ብቻ ይጠቀሙ፣ ነጠላ
DLL ፋይሎችንም ከሦስተኛ ወገን ድረ ገጾች ፈጽሞ አያውርዱ።

የMicrosoft ኦፊሴላዊ መረጃ፦
https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist

MEDIA FOUNDATION
----------------

የWindows N እትሞች ለድምፅና ሚዲያ ተግባራት Microsoft Media Feature Packን
ሊፈልጉ ይችላሉ። Media Feature Pack በተለምዶ በWindows Optional Features ውስጥ
ይገኛል። በአንዳንድ የWindows N ስሪቶች Media Feature Pack በOptional Features
ውስጥ ላይገኝ ይችላል። በዚያ ጊዜ ለእርስዎ Windows ስሪት ተስማሚ የሆነውን Media
Feature Pack ከMicrosoft ድረ ገጽ ያውርዱ።

Media Feature Packን ከጫኑ በኋላ Windowsን እንደገና ያስጀምሩ። QuisquisLingo
በራስ-ሰር አያወርደውም ወይም አይጭነውም፣ የስርዓት ቅንብሮችንም አይቀይርም።

ጽሑፍን ወደ ንግግር መቀየር
-----------------------

QuisquisLingo በWindows ውስጥ የተጫኑ የንግግር ድምፆችን ይጠቀማል። የሚገኙት
ቋንቋዎችና ድምፆች በኮምፒውተሩ ላይ በተጫኑት የWindows ቋንቋና ድምፅ ክፍሎች
ላይ ይመሰረታሉ። ተኳኋኝ ድምፅ ከሌለ ተገቢውን ክፍል በWindows ቅንብሮች ይጫኑ።

Audio Settings > Test Voice እርስዎ ያስገቡትን ጽሑፍ ብቻ ይናገራል እና
በተመረጠው ኮርስ የተዋቀረውን የድምፅ ቋንቋ ይጠቀማል።

ምዝግቦችና ምርመራ
----------------

ዋናው crash log እዚህ ይቀመጣል፦

%LOCALAPPDATA%\QuisquisLingo\Logs\quisquislingo_launcher.log

ላይ ይቆያሉ እና በራስ-ሰር አይሰቀሉም።

ችግር መፍታት
------------

1. ሙሉውን ZIP ማህደር ሙሉ በሙሉ ያውጡ።
2. ከወጣው ፓኬጅ QuisquisLingo.exeን ያስኪዱ።
3. Runtime DLL ጎድሏል ተብሎ ከተገለጸ፣ ኦፊሴላዊ Microsoft runtime installerን
   ከማሰብዎ በፊት ሙሉውን ፓኬጅ እንደገና አውርደው ያውጡ።
4. Media Feature Pack ካስፈለገ፣ ከላይ ያለውን መመሪያ ይከተሉ እና ከጫኑ በኋላ
   Windowsን እንደገና ያስጀምሩ።
5. QQL አሁንም ካልተጀመረ፣ ለድጋፍ ሙሉውን የስህተት መልዕክትና ያሉትን log
   ፋይሎች ያቆዩ።
