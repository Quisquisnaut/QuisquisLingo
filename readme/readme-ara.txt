QuisquisLingo - دليل Windows
============================

QuisquisLingo تطبيق لتعلّم اللغات موجّه إلى المتعلّمين ومنشئي الدورات. يجمع
بين الدروس المنظّمة والتمارين التفاعلية والأنشطة الصوتية وأدوات المراجعة، كما
يوفّر أدوات لإنشاء دورات لغوية وتحريرها.

صُمّم التطبيق للأشخاص الذين يريدون دراسة لغة، وكذلك للمؤلفين والمدرّسين وغيرهم
من المستخدمين الذين يريدون إنشاء دوراتهم الخاصة.

للحصول على نظرة مرئية سريعة إلى طريقة عمل QuisquisLingo، راجع الملف
QQL infographic.png المضمّن في حزمة التطبيق.

لبدء QuisquisLingo، شغّل QuisquisLingo.exe.

استخدام الحزمة
--------------

تحتوي هذه الحزمة على تطبيق QQL. استخرج أرشيف ZIP بالكامل قبل التشغيل، وأبقِ
جميع الملفات المرفقة ومجلد data معًا. لا توزّع ملفات EXE أو DLL منفردة، ولا
تنقلها أو تحذفها أو تغيّر أسماءها.

فحوص بدء التشغيل
----------------

قبل التشغيل، يفحص QuisquisLingo ملفات الحزمة المطلوبة والتوافق مع Windows و
Media Foundation. لا تنزّل هذه الفحوص أي برنامج ولا تثبّته، ولا تطلب صلاحيات
مرتفعة، ولا تغيّر السجل أو تعدّل Windows.

عند وجود مشكلة يمكن تجاوزها، تظهر رسالة واحدة تحتوي على Continue anyway و
Cancel. يحاول Continue anyway تشغيل QQL، بينما يغلقه Cancel. إذا كان ملف أساسي
مفقودًا، تعرض الرسالة Close لأن الحزمة يجب أن تُنزّل وتُستخرج من جديد.

دعم Wine تجريبي. قد يؤدي غياب Media Foundation في Wine إلى منع التشغيل أو
تعطّل ميزات الصوت والوسائط.

بيئة MICROSOFT VISUAL C++
-------------------------

تتضمن الحزمة الكاملة ملفات بيئة Microsoft Visual C++ x64 التالية:

msvcp140.dll
vcruntime140.dll
vcruntime140_1.dll

إذا كان أحدها مفقودًا، فنزّل حزمة QuisquisLingo الكاملة لنظام Windows من جديد
واستخرجها بالكامل. استخدم مصادر Microsoft الرسمية فقط لمثبّتات بيئة التشغيل،
ولا تنزّل أبدًا ملفات DLL منفردة من مواقع جهات خارجية.

معلومات Microsoft الرسمية:
https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist

MEDIA FOUNDATION
----------------

قد تتطلب إصدارات Windows N تثبيت Microsoft Media Feature Pack لتشغيل وظائف
الصوت والوسائط. تتوفر Media Feature Pack عادةً ضمن الميزات الاختيارية في
Windows. في بعض إصدارات Windows N قد لا تتوفر هناك. في هذه الحالة، نزّل Media
Feature Pack المناسبة لإصدار Windows لديك من موقع Microsoft.

أعد تشغيل Windows بعد تثبيت Media Feature Pack. لا يقوم QuisquisLingo بتنزيلها
أو تثبيتها تلقائيًا ولا يغيّر إعدادات النظام.

تحويل النص إلى كلام
-------------------

يستخدم QuisquisLingo الأصوات المثبّتة في Windows. تعتمد اللغات والأصوات
المتاحة على مكوّنات اللغة والصوت المثبّتة على الكمبيوتر. إذا لم يتوفر صوت
متوافق، فثبّت المكوّن المناسب من إعدادات Windows.

ينطق Audio Settings > Test Voice النص الذي تدخله فقط، ويستخدم لغة الصوت
المحددة في الدورة المختارة.

السجلات والتشخيص
----------------

يُحفظ سجل الأعطال الرئيسي في:

Documents\QuisquisLingo\Logs\quisquislingo_crash.log

يُحفظ سجل فحص بدء التشغيل في:

%LOCALAPPDATA%\QuisquisLingo\Logs\quisquislingo_launcher.log

يعرض Settings > Debug خيارات التشخيص. تبقى السجلات على الكمبيوتر المحلي ولا
تُرفع تلقائيًا.

استكشاف الأخطاء وإصلاحها
------------------------

1. استخرج أرشيف ZIP الكامل بالكامل.
2. شغّل QuisquisLingo.exe من الحزمة المستخرجة.
3. إذا أُبلغ عن ملف DLL مفقود لبيئة التشغيل، فأعد تنزيل الحزمة الكاملة
   واستخراجها قبل التفكير في مثبّت رسمي من Microsoft.
4. إذا كانت Media Feature Pack مطلوبة، فاتبع الإرشادات أعلاه وأعد تشغيل
   Windows بعد التثبيت.
5. إذا استمر تعذّر تشغيل QQL، فاحتفظ برسالة الخطأ الكاملة وملفات السجل المتاحة
   لطلب الدعم.
