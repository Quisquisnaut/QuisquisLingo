QuisquisLingo - Ръководство за Windows
=====================================

QuisquisLingo е приложение за изучаване на езици, предназначено за учащи и
създатели на курсове. То съчетава структурирани уроци, интерактивни упражнения,
аудио дейности и инструменти за преговор, като същевременно предлага инструменти
за създаване и редактиране на езикови курсове.

Приложението е предназначено както за хора, които искат да изучават език, така
и за автори, преподаватели и други потребители, които искат да създават свои
курсове.

За бърз визуален преглед на начина, по който работи QuisquisLingo, вижте
QQL infographic.png, включена в пакета на приложението.

За да стартирате QuisquisLingo, изпълнете QuisquisLingo.exe.

ИЗПОЛЗВАНЕ НА ПАКЕТА
--------------------

Този пакет съдържа приложението QQL. Разархивирайте целия ZIP архив преди
стартиране и пазете заедно всички предоставени файлове и папката data. Не
разпространявайте, премествайте, изтривайте или преименувайте отделни EXE или DLL
файлове.

ПРОВЕРКИ ПРИ СТАРТИРАНЕ
-----------------------

Преди стартиране QuisquisLingo проверява необходимите файлове в пакета,
съвместимостта с Windows и Media Foundation. Тези проверки никога не изтеглят
или инсталират софтуер, не искат администраторски права, не променят registry и
не изменят Windows.

При проблем, след който може да се продължи, се показва едно съобщение с
Continue anyway и Cancel. Continue anyway опитва да стартира QQL; Cancel го
затваря. Ако липсва основен програмен файл, съобщението предлага Close, защото
пакетът трябва да бъде изтеглен отново и напълно разархивиран.

Поддръжката на Wine е Experimental. Липсата на Media Foundation под Wine може
да попречи на стартирането или на работата на аудио и мултимедийните функции.

MICROSOFT VISUAL C++ RUNTIME
----------------------------

Пълният пакет включва следните runtime файлове на Microsoft Visual C++ x64:

msvcp140.dll
vcruntime140.dll
vcruntime140_1.dll

Ако някой липсва, изтеглете отново пълния пакет QuisquisLingo за Windows и го
разархивирайте изцяло. Използвайте само официални източници на Microsoft за
runtime installer и никога не изтегляйте отделни DLL файлове от сайтове на трети
страни.

Официална информация от Microsoft:
https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist

MEDIA FOUNDATION
----------------

Изданията Windows N може да изискват Microsoft Media Feature Pack за аудио и
мултимедийни функции. Media Feature Pack обикновено е наличен в Windows Optional
Features. В някои версии на Windows N Media Feature Pack може да не се предлага
в Optional Features. В такъв случай изтеглете от уебсайта на Microsoft
подходящия Media Feature Pack за вашата версия на Windows.

Рестартирайте Windows след инсталирането на Media Feature Pack. QuisquisLingo не
го изтегля или инсталира автоматично и не променя системните настройки.

ПРЕОБРАЗУВАНЕ НА ТЕКСТ В РЕЧ
----------------------------

QuisquisLingo използва гласовете за реч, инсталирани в Windows. Наличните езици
и гласове зависят от езиковите и гласовите компоненти на Windows, инсталирани на
компютъра. Ако няма съвместим глас, инсталирайте подходящия компонент чрез
настройките на Windows.

Audio Settings > Test Voice произнася само въведения от вас текст и използва
езика на гласа, конфигуриран от избрания курс.

ДНЕВНИЦИ И ДИАГНОСТИКА
----------------------

Основният crash log се съхранява тук:

Documents\QuisquisLingo\Logs\quisquislingo_crash.log

Log от проверката при стартиране се съхранява тук:

%LOCALAPPDATA%\QuisquisLingo\Logs\quisquislingo_launcher.log

Settings > Debug показва диагностични опции. Log файловете остават на локалния
компютър и не се качват автоматично.

ОТСТРАНЯВАНЕ НА НЕИЗПРАВНОСТИ
-----------------------------

1. Разархивирайте напълно целия ZIP архив.
2. Стартирайте QuisquisLingo.exe от разархивирания пакет.
3. Ако бъде съобщено, че липсва runtime DLL, изтеглете и разархивирайте отново
   пълния пакет, преди да обмислите официален Microsoft runtime installer.
4. Ако е необходим Media Feature Pack, следвайте указанията по-горе и
   рестартирайте Windows след инсталирането.
5. Ако QQL все още не се стартира, запазете пълното съобщение за грешка и
   наличните log файлове за поддръжка.
