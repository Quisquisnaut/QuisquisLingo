QuisquisLingo — руководство для Windows
======================================

QuisquisLingo — приложение для изучения языков и создания учебных курсов. Оно
объединяет структурированные уроки, интерактивные упражнения, аудиозадания и
средства повторения, а также позволяет создавать и редактировать языковые курсы.

Приложение предназначено как для тех, кто хочет изучать язык, так и для
авторов, преподавателей и других пользователей, желающих создавать собственные
курсы.

Краткий наглядный обзор работы QuisquisLingo находится в файле
QQL infographic.png, включённом в пакет приложения.

Чтобы запустить QuisquisLingo, выполните QuisquisLingo.exe.

ИСПОЛЬЗОВАНИЕ ПАКЕТА
--------------------

Этот пакет содержит приложение QQL. Перед запуском полностью распакуйте архив
ZIP и храните вместе все поставляемые файлы и папку data. Не распространяйте,
не перемещайте, не удаляйте и не переименовывайте отдельные файлы EXE или DLL.

ПРОВЕРКИ ПРИ ЗАПУСКЕ
--------------------

Перед запуском QuisquisLingo проверяет необходимые файлы пакета, совместимость
с Windows и Media Foundation. Эти проверки не загружают и не устанавливают
программы, не запрашивают повышение прав, не изменяют реестр и настройки
Windows.

При устранимой проблеме появляется одно сообщение с кнопками Continue anyway и
Cancel. Continue anyway пытается запустить QQL, а Cancel закрывает его. Если
отсутствует обязательный файл программы, доступна только кнопка Close, поскольку
пакет необходимо загрузить и распаковать заново.

Поддержка Wine является экспериментальной. Отсутствие Media Foundation в Wine
может помешать запуску или работе звуковых и мультимедийных функций.

СРЕДА MICROSOFT VISUAL C++
--------------------------

Полный пакет содержит следующие файлы среды Microsoft Visual C++ x64:

msvcp140.dll
vcruntime140.dll
vcruntime140_1.dll

Если один из них отсутствует, снова загрузите полный пакет QuisquisLingo для
Windows и полностью распакуйте его. Загружайте установщики среды выполнения
только из официальных источников Microsoft и никогда не скачивайте отдельные
DLL со сторонних сайтов.

Официальная информация Microsoft:
https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist

MEDIA FOUNDATION
----------------

Для звуковых и мультимедийных функций в редакциях Windows N может потребоваться
Microsoft Media Feature Pack. Обычно Media Feature Pack доступен в разделе
дополнительных компонентов Windows. В некоторых вариантах Windows N он может
отсутствовать в этом разделе. В таком случае загрузите с сайта Microsoft пакет
Media Feature Pack, подходящий для вашей версии Windows.

После установки Media Feature Pack перезапустите Windows. QuisquisLingo не
загружает и не устанавливает его автоматически и не изменяет системные
настройки.

СИНТЕЗ РЕЧИ
-----------

QuisquisLingo использует голоса, установленные в Windows. Доступные языки и
голоса зависят от языковых и голосовых компонентов, установленных на компьютере.
Если совместимого голоса нет, установите подходящий компонент через параметры
Windows.

Audio Settings > Test Voice произносит только введённый текст и использует язык
голоса, заданный выбранным курсом.

ЖУРНАЛЫ И ДИАГНОСТИКА
---------------------

Основной журнал сбоев хранится по адресу:

Documents\QuisquisLingo\Logs\quisquislingo_crash.log

Журнал проверки запуска хранится по адресу:

%LOCALAPPDATA%\QuisquisLingo\Logs\quisquislingo_launcher.log

Settings > Debug показывает параметры диагностики. Журналы остаются на
локальном компьютере и не отправляются автоматически.

УСТРАНЕНИЕ НЕПОЛАДОК
--------------------

1. Полностью распакуйте весь архив ZIP.
2. Запустите QuisquisLingo.exe из распакованного пакета.
3. Если сообщается об отсутствующей DLL среды выполнения, снова загрузите и
   распакуйте полный пакет, прежде чем использовать официальный установщик
   Microsoft.
4. Если требуется Media Feature Pack, следуйте приведённым выше рекомендациям и
   перезапустите Windows после установки.
5. Если QQL по-прежнему не запускается, сохраните полное сообщение об ошибке и
   доступные файлы журналов для службы поддержки.
