QuisquisLingo - คู่มือ Windows
==============================

QuisquisLingo เป็นแอปพลิเคชันเรียนภาษาสำหรับผู้เรียนและผู้สร้างหลักสูตร โดยรวม
บทเรียนที่มีโครงสร้าง แบบฝึกหัดเชิงโต้ตอบ กิจกรรมเสียง และเครื่องมือทบทวนไว้ด้วยกัน
พร้อมทั้งมีเครื่องมือสำหรับสร้างและแก้ไขหลักสูตรภาษา

โปรแกรมนี้ออกแบบมาทั้งสำหรับผู้ที่ต้องการเรียนภาษา และสำหรับผู้เขียน ครู หรือผู้ใช้
คนอื่นที่ต้องการสร้างหลักสูตรของตนเอง

หากต้องการดูภาพรวมอย่างรวดเร็วว่า QuisquisLingo ทำงานอย่างไร โปรดดู
QQL infographic.png ซึ่งรวมอยู่ในแพ็กเกจแอปพลิเคชัน

หากต้องการเริ่ม QuisquisLingo ให้เรียกใช้ QuisquisLingo.exe

การใช้แพ็กเกจ
-------------

แพ็กเกจนี้มีแอปพลิเคชัน QQL โปรดแตกไฟล์ ZIP ทั้งหมดก่อนเริ่มใช้งาน และเก็บไฟล์ทั้งหมด
ที่ให้มากับโฟลเดอร์ data ไว้ด้วยกัน อย่าแจกจ่าย ย้าย ลบ หรือเปลี่ยนชื่อไฟล์ EXE หรือ DLL
แยกจากกัน

การตรวจสอบเมื่อเริ่มต้น
----------------------

ก่อนเริ่มทำงาน QuisquisLingo จะตรวจสอบไฟล์แพ็กเกจที่จำเป็น ความเข้ากันได้กับ Windows
และ Media Foundation การตรวจสอบเหล่านี้จะไม่ดาวน์โหลดหรือติดตั้งซอฟต์แวร์ ไม่ขอสิทธิ์
ผู้ดูแลระบบ ไม่เปลี่ยน registry และไม่แก้ไข Windows

หากเป็นปัญหาที่ยังสามารถดำเนินการต่อได้ จะมีข้อความหนึ่งรายการพร้อม Continue anyway
และ Cancel โดย Continue anyway จะลองเริ่ม QQL ส่วน Cancel จะปิดโปรแกรม หากไฟล์
โปรแกรมที่จำเป็นหายไป ข้อความจะแสดง Close เพราะต้องดาวน์โหลดและแตกแพ็กเกจทั้งหมดใหม่

การรองรับ Wine อยู่ในสถานะ Experimental การไม่มี Media Foundation ใน Wine อาจทำให้
เปิดโปรแกรมไม่ได้ หรือทำให้คุณสมบัติเสียงและสื่อไม่ทำงาน

MICROSOFT VISUAL C++ RUNTIME
----------------------------

แพ็กเกจฉบับสมบูรณ์มีไฟล์ runtime ของ Microsoft Visual C++ x64 ดังต่อไปนี้:

msvcp140.dll
vcruntime140.dll
vcruntime140_1.dll

หากไฟล์ใดหายไป ให้ดาวน์โหลดแพ็กเกจ Windows ของ QuisquisLingo ฉบับสมบูรณ์อีกครั้ง
และแตกไฟล์ทั้งหมด ใช้เฉพาะแหล่งข้อมูลอย่างเป็นทางการของ Microsoft สำหรับ runtime
installer และอย่าดาวน์โหลดไฟล์ DLL แยกจากเว็บไซต์ของบุคคลที่สาม

ข้อมูลอย่างเป็นทางการจาก Microsoft:
https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist

MEDIA FOUNDATION
----------------

Windows N edition อาจต้องใช้ Microsoft Media Feature Pack เพื่อให้คุณสมบัติเสียงและ
สื่อทำงาน โดยปกติ Media Feature Pack จะอยู่ใน Windows Optional Features ใน Windows N
บางเวอร์ชัน Media Feature Pack อาจไม่มีใน Optional Features ในกรณีนี้ ให้ดาวน์โหลด
Media Feature Pack ที่เหมาะกับเวอร์ชัน Windows ของคุณจากเว็บไซต์ Microsoft

เริ่ม Windows ใหม่หลังติดตั้ง Media Feature Pack QuisquisLingo จะไม่ดาวน์โหลดหรือ
ติดตั้งแพ็กนี้โดยอัตโนมัติ และจะไม่เปลี่ยนการตั้งค่าระบบ

TEXT-TO-SPEECH
--------------

QuisquisLingo ใช้เสียงพูดที่ติดตั้งใน Windows ภาษาและเสียงที่พร้อมใช้งานขึ้นอยู่กับ
องค์ประกอบภาษาและเสียงของ Windows ที่ติดตั้งในคอมพิวเตอร์ หากไม่มีเสียงที่เข้ากันได้
ให้ติดตั้งองค์ประกอบที่เหมาะสมผ่านการตั้งค่า Windows

Audio Settings > Test Voice จะอ่านเฉพาะข้อความที่คุณป้อน และใช้ภาษาของเสียงที่กำหนด
ไว้สำหรับหลักสูตรที่เลือก

LOG และการวินิจฉัย
-----------------

Crash log หลักจัดเก็บไว้ที่:

Documents\QuisquisLingo\Logs\quisquislingo_crash.log

Log การตรวจสอบเมื่อเริ่มต้นจัดเก็บไว้ที่:

%LOCALAPPDATA%\QuisquisLingo\Logs\quisquislingo_launcher.log

Settings > Debug มีตัวเลือกการวินิจฉัย Log จะอยู่ในคอมพิวเตอร์เครื่องนั้นและจะไม่ถูก
upload โดยอัตโนมัติ

การแก้ไขปัญหา
-------------

1. แตกไฟล์ ZIP ทั้งหมดอย่างสมบูรณ์
2. เรียกใช้ QuisquisLingo.exe จากแพ็กเกจที่แตกไฟล์แล้ว
3. หากมีรายงานว่า runtime DLL หายไป ให้ดาวน์โหลดและแตกแพ็กเกจฉบับสมบูรณ์อีกครั้ง
   ก่อนพิจารณา runtime installer อย่างเป็นทางการของ Microsoft
4. หากจำเป็นต้องใช้ Media Feature Pack ให้ทำตามคำแนะนำด้านบนและเริ่ม Windows ใหม่
   หลังติดตั้ง
5. หาก QQL ยังไม่เริ่มทำงาน ให้เก็บข้อความข้อผิดพลาดฉบับเต็มและไฟล์ log ที่มีไว้
   สำหรับขอความช่วยเหลือ
