QuisquisLingo - Windows మార్గదర్శిని
==================================

QuisquisLingo అనేది భాష నేర్చుకునేవారు మరియు కోర్సులను రూపొందించేవారి కోసం
ఉద్దేశించిన భాషా అభ్యాస అనువర్తనం. ఇది క్రమబద్ధమైన పాఠాలు, పరస్పర చర్యతో కూడిన
అభ్యాసాలు, ఆడియో కార్యకలాపాలు మరియు పునశ్చరణ సాధనాలను కలిపి అందించడంతో పాటు,
భాషా కోర్సులను సృష్టించడానికి మరియు సవరించడానికి సాధనాలను కూడా అందిస్తుంది.

ఒక భాషను నేర్చుకోవాలనుకునేవారితో పాటు, తమ సొంత కోర్సులను రూపొందించాలనుకునే
రచయితలు, ఉపాధ్యాయులు మరియు ఇతర వినియోగదారుల కోసం ఇది రూపొందించబడింది.

QuisquisLingo ఎలా పనిచేస్తుందో త్వరిత దృశ్య పరిచయం కోసం, అనువర్తన ప్యాకేజీలో
చేర్చిన QQL infographic.png చూడండి.

QuisquisLingo ప్రారంభించడానికి QuisquisLingo.exe అమలు చేయండి.

ప్యాకేజీని ఉపయోగించడం
--------------------

ఈ ప్యాకేజీలో QQL అనువర్తనం ఉంటుంది. ప్రారంభించే ముందు మొత్తం ZIP ఆర్కైవ్‌ను
వెలికితీసి, అందించిన అన్ని ఫైళ్లను మరియు data ఫోల్డర్‌ను కలిపి ఉంచండి. విడివిడిగా
EXE లేదా DLL ఫైళ్లను పంపిణీ చేయవద్దు, తరలించవద్దు, తొలగించవద్దు లేదా పేరు
మార్చవద్దు.

ప్రారంభ తనిఖీలు
---------------

ప్రారంభించే ముందు QuisquisLingo అవసరమైన ప్యాకేజీ ఫైళ్లు, Windows అనుకూలత మరియు
Media Foundation‌ను తనిఖీ చేస్తుంది. ఈ తనిఖీలు ఎప్పుడూ సాఫ్ట్‌వేర్‌ను డౌన్‌లోడ్
లేదా ఇన్‌స్టాల్ చేయవు, నిర్వాహక అనుమతిని కోరవు, registry లేదా Windows‌ను
మార్చవు.

సమస్య ఉన్నప్పటికీ కొనసాగడం సాధ్యమైతే, Continue anyway మరియు Cancel ఉన్న ఒకే
సందేశం కనిపిస్తుంది. Continue anyway QQL ప్రారంభించడానికి ప్రయత్నిస్తుంది;
Cancel దాన్ని మూసివేస్తుంది. అత్యవసర ప్రోగ్రామ్ ఫైల్ లేకపోతే, ప్యాకేజీని మళ్లీ
డౌన్‌లోడ్ చేసి పూర్తిగా వెలికితీయాల్సి ఉంటుంది కాబట్టి సందేశం Close‌ను చూపిస్తుంది.

Wine మద్దతు Experimental స్థితిలో ఉంది. Wine‌లో Media Foundation లేకపోతే
ప్రారంభం ఆగిపోవచ్చు లేదా ఆడియో మరియు మీడియా లక్షణాలు పనిచేయకపోవచ్చు.

MICROSOFT VISUAL C++ RUNTIME
----------------------------

పూర్తి ప్యాకేజీలో ఈ Microsoft Visual C++ x64 runtime ఫైళ్లు ఉంటాయి:

msvcp140.dll
vcruntime140.dll
vcruntime140_1.dll

వీటిలో ఏదైనా లేకపోతే, పూర్తి QuisquisLingo Windows ప్యాకేజీని మళ్లీ డౌన్‌లోడ్
చేసి పూర్తిగా వెలికితీయండి. Runtime installer కోసం Microsoft అధికారిక మూలాలను
మాత్రమే ఉపయోగించండి; మూడవ పక్ష వెబ్‌సైట్ల నుంచి విడి DLL ఫైళ్లను ఎప్పుడూ
డౌన్‌లోడ్ చేయవద్దు.

Microsoft అధికారిక సమాచారం:
https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist

MEDIA FOUNDATION
----------------

Windows N ఎడిషన్లలో ఆడియో మరియు మీడియా కార్యాచరణకు Microsoft Media Feature Pack
అవసరం కావచ్చు. Media Feature Pack సాధారణంగా Windows Optional Features‌లో
అందుబాటులో ఉంటుంది. Windows N యొక్క కొన్ని సంస్కరణల్లో Media Feature Pack
Optional Features‌లో ఉండకపోవచ్చు. అలాంటప్పుడు మీ Windows సంస్కరణకు సరిపోయే
Media Feature Pack‌ను Microsoft వెబ్‌సైట్ నుంచి డౌన్‌లోడ్ చేయండి.

Media Feature Pack‌ను ఇన్‌స్టాల్ చేసిన తర్వాత Windows‌ను పునఃప్రారంభించండి.
QuisquisLingo దాన్ని స్వయంచాలకంగా డౌన్‌లోడ్ లేదా ఇన్‌స్టాల్ చేయదు మరియు సిస్టమ్
సెట్టింగులను మార్చదు.

వచనం నుంచి మాటకు
-----------------

QuisquisLingo Windows‌లో ఇన్‌స్టాల్ చేసిన ప్రసంగ స్వరాలను ఉపయోగిస్తుంది. అందుబాటులో
ఉన్న భాషలు మరియు స్వరాలు కంప్యూటర్‌లో ఇన్‌స్టాల్ చేసిన Windows భాషా మరియు స్వర
భాగాలపై ఆధారపడతాయి. అనుకూలమైన స్వరం లేకపోతే, Windows సెట్టింగుల ద్వారా తగిన
భాగాన్ని ఇన్‌స్టాల్ చేయండి.

Audio Settings > Test Voice మీరు నమోదు చేసిన వచనాన్ని మాత్రమే పలుకుతుంది మరియు
ఎంచుకున్న కోర్సులో అమర్చిన స్వర భాషను ఉపయోగిస్తుంది.

లాగ్‌లు మరియు నిర్ధారణ
---------------------

ప్రధాన crash log ఇక్కడ నిల్వ ఉంటుంది:

Documents\QuisquisLingo\Logs\quisquislingo_crash.log

ప్రారంభ తనిఖీ log ఇక్కడ నిల్వ ఉంటుంది:

%LOCALAPPDATA%\QuisquisLingo\Logs\quisquislingo_launcher.log

Settings > Debug నిర్ధారణ ఎంపికలను చూపిస్తుంది. Log ఫైళ్లు స్థానిక కంప్యూటర్‌లోనే
ఉంటాయి మరియు స్వయంచాలకంగా అప్‌లోడ్ కావు.

సమస్య పరిష్కారం
---------------

1. మొత్తం ZIP ఆర్కైవ్‌ను పూర్తిగా వెలికితీయండి.
2. వెలికితీసిన ప్యాకేజీ నుంచి QuisquisLingo.exe అమలు చేయండి.
3. Runtime DLL లేదని నివేదిస్తే, అధికారిక Microsoft runtime installer‌ను
   పరిగణించే ముందు పూర్తి ప్యాకేజీని మళ్లీ డౌన్‌లోడ్ చేసి వెలికితీయండి.
4. Media Feature Pack అవసరమైతే, పై మార్గదర్శకాన్ని అనుసరించి ఇన్‌స్టాల్ చేసిన
   తర్వాత Windows‌ను పునఃప్రారంభించండి.
5. QQL ఇంకా ప్రారంభం కాకపోతే, సహాయం కోసం పూర్తి దోష సందేశం మరియు అందుబాటులో ఉన్న
   log ఫైళ్లను ఉంచండి.
