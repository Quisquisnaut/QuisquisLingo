QuisquisLingo — посібник для Windows
===================================

QuisquisLingo — це застосунок для вивчення мов, призначений для учнів і творців
курсів. Він поєднує структуровані уроки, інтерактивні вправи, аудіозавдання та
засоби повторення, а також надає інструменти для створення й редагування мовних
курсів.

Він розрахований як на людей, які хочуть вивчати мову, так і на авторів,
викладачів та інших користувачів, які бажають створювати власні курси.

Щоб швидко ознайомитися з роботою QuisquisLingo, перегляньте
QQL infographic.png, що входить до пакета застосунку.

Щоб запустити QuisquisLingo, виконайте QuisquisLingo.exe.

ВИКОРИСТАННЯ ПАКЕТА
-------------------

Цей пакет містить застосунок QQL. Перед запуском повністю розпакуйте ZIP-архів
і зберігайте разом усі надані файли та папку data. Не розповсюджуйте,
не переміщуйте, не видаляйте й не перейменовуйте окремі файли EXE або DLL.

ПЕРЕВІРКИ ПІД ЧАС ЗАПУСКУ
-------------------------

Перед запуском QuisquisLingo перевіряє потрібні файли пакета, сумісність із
Windows і Media Foundation. Ці перевірки ніколи не завантажують і не встановлюють
програмне забезпечення, не запитують права адміністратора, не змінюють реєстр
або Windows.

Якщо після виявленої проблеми можна продовжити, з’являється одне повідомлення
з Continue anyway і Cancel. Continue anyway намагається запустити QQL, а Cancel
закриває його. Якщо немає важливого програмного файла, повідомлення пропонує
Close, оскільки пакет потрібно повторно завантажити та повністю розпакувати.

Підтримка Wine має статус Experimental. Відсутність Media Foundation у Wine
може завадити запуску або роботі звукових і мультимедійних функцій.

MICROSOFT VISUAL C++ RUNTIME
----------------------------

Повний пакет містить такі файли Microsoft Visual C++ x64 runtime:

msvcp140.dll
vcruntime140.dll
vcruntime140_1.dll

Якщо одного з них немає, повторно завантажте повний пакет QuisquisLingo для
Windows і розпакуйте його повністю. Завантажуйте runtime installer лише з
офіційних джерел Microsoft і ніколи не завантажуйте окремі файли DLL зі сторонніх
сайтів.

Офіційна інформація Microsoft:
https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist

MEDIA FOUNDATION
----------------

У випусках Windows N для роботи зі звуком і мультимедіа може знадобитися
Microsoft Media Feature Pack. Зазвичай Media Feature Pack доступний у Windows
Optional Features. У деяких версіях Windows N Media Feature Pack може бути
відсутній в Optional Features. У такому разі завантажте відповідний до вашої
версії Windows Media Feature Pack із вебсайту Microsoft.

Після встановлення Media Feature Pack перезапустіть Windows. QuisquisLingo не
завантажує й не встановлює його автоматично та не змінює системні параметри.

TEXT-TO-SPEECH
--------------

QuisquisLingo використовує голоси мовлення, установлені у Windows. Доступні мови
й голоси залежать від мовних і голосових компонентів Windows, установлених на
комп’ютері. Якщо сумісного голосу немає, установіть відповідний компонент через
параметри Windows.

Audio Settings > Test Voice озвучує лише введений вами текст і використовує мову
голосу, налаштовану для вибраного курсу.

ЖУРНАЛИ ТА ДІАГНОСТИКА
----------------------

Основний crash log зберігається тут:

Documents\QuisquisLingo\Logs\quisquislingo_crash.log

Log перевірок запуску зберігається тут:

%LOCALAPPDATA%\QuisquisLingo\Logs\quisquislingo_launcher.log

Settings > Debug містить діагностичні параметри. Log залишаються на локальному
комп’ютері й не надсилаються автоматично.

УСУНЕННЯ НЕСПРАВНОСТЕЙ
----------------------

1. Повністю розпакуйте весь ZIP-архів.
2. Запустіть QuisquisLingo.exe з розпакованого пакета.
3. Якщо повідомлено про відсутність runtime DLL, повторно завантажте й розпакуйте
   повний пакет, перш ніж розглядати офіційний runtime installer Microsoft.
4. Якщо потрібен Media Feature Pack, виконайте наведені вище вказівки та
   перезапустіть Windows після встановлення.
5. Якщо QQL усе одно не запускається, збережіть повний текст помилки й доступні
   файли log для звернення по допомогу.
