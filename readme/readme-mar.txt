QuisquisLingo - Windows मार्गदर्शिका
==================================

QuisquisLingo हे भाषा शिकणारे आणि अभ्यासक्रम तयार करणारे यांच्यासाठी भाषा
शिकण्याचे ॲप्लिकेशन आहे. यात संरचित धडे, परस्परसंवादी सराव, ऑडिओ उपक्रम आणि
उजळणीची साधने एकत्र आहेत, तसेच भाषा अभ्यासक्रम तयार व संपादित करण्याची साधनेही
दिलेली आहेत.

भाषा शिकू इच्छिणाऱ्या लोकांसाठी तसेच स्वतःचे अभ्यासक्रम तयार करू इच्छिणाऱ्या
लेखक, शिक्षक आणि इतर वापरकर्त्यांसाठी ते तयार केले आहे.

QuisquisLingo कसे कार्य करते याचा झटपट दृश्य आढावा घेण्यासाठी ॲप्लिकेशनच्या
पॅकेजमध्ये समाविष्ट असलेली QQL infographic.png पहा.

QuisquisLingo सुरू करण्यासाठी QuisquisLingo.exe चालवा.

पॅकेजचा वापर
------------

या पॅकेजमध्ये QQL ॲप्लिकेशन आहे. सुरू करण्यापूर्वी संपूर्ण ZIP संग्रह बाहेर
काढा आणि दिलेल्या सर्व फाइल व data फोल्डर एकत्र ठेवा. स्वतंत्र EXE किंवा DLL
फाइल वितरित, हलवू, हटवू किंवा त्यांची नावे बदलू नका.

सुरुवातीच्या तपासण्या
--------------------

सुरू होण्यापूर्वी QuisquisLingo आवश्यक पॅकेज फाइल, Windows सुसंगतता आणि Media
Foundation तपासते. या तपासण्या कधीही सॉफ्टवेअर डाउनलोड किंवा इन्स्टॉल करत नाहीत,
प्रशासक परवानगी मागत नाहीत, registry किंवा Windows बदलत नाहीत.

समस्या असूनही पुढे जाता येत असेल, तर Continue anyway आणि Cancel असलेला एकच
संदेश दिसतो. Continue anyway QQL सुरू करण्याचा प्रयत्न करते; Cancel ते बंद करते.
आवश्यक प्रोग्राम फाइल नसेल तर संदेशात Close दिले जाते, कारण पॅकेज पुन्हा
डाउनलोड करून पूर्णपणे बाहेर काढणे आवश्यक असते.

Wine सहाय्य Experimental आहे. Wine मध्ये Media Foundation नसल्यास प्रोग्राम सुरू
होऊ शकणार नाही किंवा ऑडिओ आणि मीडिया वैशिष्ट्ये कार्य करणार नाहीत.

MICROSOFT VISUAL C++ RUNTIME
----------------------------

संपूर्ण पॅकेजमध्ये पुढील Microsoft Visual C++ x64 runtime फाइल आहेत:

msvcp140.dll
vcruntime140.dll
vcruntime140_1.dll

यापैकी एखादी फाइल नसेल तर संपूर्ण QuisquisLingo Windows पॅकेज पुन्हा डाउनलोड
करून पूर्णपणे बाहेर काढा. Runtime installer साठी फक्त अधिकृत Microsoft स्रोत
वापरा आणि तृतीय-पक्ष वेबसाइटवरून स्वतंत्र DLL फाइल कधीही डाउनलोड करू नका.

Microsoft ची अधिकृत माहिती:
https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist

MEDIA FOUNDATION
----------------

Windows N आवृत्त्यांमध्ये ऑडिओ आणि मीडिया कार्यांसाठी Microsoft Media Feature
Pack आवश्यक असू शकतो. Media Feature Pack सामान्यतः Windows Optional Features
मध्ये उपलब्ध असतो. Windows N च्या काही आवृत्त्यांमध्ये Media Feature Pack
Optional Features मध्ये उपलब्ध नसेल. अशा वेळी तुमच्या Windows आवृत्तीसाठी योग्य
Media Feature Pack Microsoft वेबसाइटवरून डाउनलोड करा.

Media Feature Pack इन्स्टॉल केल्यानंतर Windows पुन्हा सुरू करा. QuisquisLingo
तो आपोआप डाउनलोड किंवा इन्स्टॉल करत नाही आणि सिस्टम सेटिंग्ज बदलत नाही.

मजकुराचे भाषणात रूपांतर
----------------------

QuisquisLingo Windows मध्ये इन्स्टॉल केलेले वाणीचे आवाज वापरते. उपलब्ध भाषा आणि
आवाज संगणकावर इन्स्टॉल केलेल्या Windows भाषा आणि आवाज घटकांवर अवलंबून असतात.
सुसंगत आवाज उपलब्ध नसेल तर Windows सेटिंग्जमधून योग्य घटक इन्स्टॉल करा.

Audio Settings > Test Voice फक्त तुम्ही प्रविष्ट केलेला मजकूर बोलते आणि निवडलेल्या
अभ्यासक्रमात संरचित केलेली आवाजाची भाषा वापरते.

नोंदी आणि निदान
--------------

मुख्य crash log येथे साठवला जातो:

Documents\QuisquisLingo\Logs\quisquislingo_crash.log

सुरुवातीच्या तपासणीचा log येथे साठवला जातो:

%LOCALAPPDATA%\QuisquisLingo\Logs\quisquislingo_launcher.log

Settings > Debug निदान पर्याय दाखवते. Log फाइल स्थानिक संगणकावरच राहतात आणि
आपोआप अपलोड होत नाहीत.

समस्यानिवारण
------------

1. संपूर्ण ZIP संग्रह पूर्णपणे बाहेर काढा.
2. बाहेर काढलेल्या पॅकेजमधून QuisquisLingo.exe चालवा.
3. Runtime DLL नसल्याचे कळवले गेल्यास, अधिकृत Microsoft runtime installer चा
   विचार करण्यापूर्वी संपूर्ण पॅकेज पुन्हा डाउनलोड करून बाहेर काढा.
4. Media Feature Pack आवश्यक असल्यास, वरील मार्गदर्शन पाळा आणि इन्स्टॉल केल्यानंतर
   Windows पुन्हा सुरू करा.
5. QQL तरीही सुरू होत नसेल तर मदतीसाठी संपूर्ण त्रुटी संदेश आणि उपलब्ध log फाइल
   जतन करा.
