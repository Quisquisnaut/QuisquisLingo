QuisquisLingo - راهنمای Windows
===============================

QuisquisLingo برنامه‌ای برای یادگیری زبان است که برای زبان‌آموزان و سازندگان
دوره طراحی شده است. این برنامه درس‌های ساختاریافته، تمرین‌های تعاملی،
فعالیت‌های صوتی و ابزارهای مرور را در کنار ابزارهای ساخت و ویرایش دوره‌های
زبان ارائه می‌کند.

این برنامه هم برای افرادی است که می‌خواهند زبانی را بیاموزند و هم برای
نویسندگان، آموزگاران و کاربران دیگری که قصد دارند دوره‌های خود را بسازند.

برای آشنایی تصویری و سریع با نحوه کار QuisquisLingo، فایل
QQL infographic.png را که در بسته برنامه قرار دارد ببینید.

برای اجرای QuisquisLingo، فایل QuisquisLingo.exe را اجرا کنید.

استفاده از بسته
---------------

این بسته شامل برنامه QQL است. پیش از اجرا، کل بایگانی ZIP را استخراج کنید و
همه فایل‌های ارائه‌شده و پوشه data را کنار هم نگه دارید. فایل‌های EXE یا DLL را
به‌تنهایی جابه‌جا، توزیع، حذف یا تغییرنام ندهید.

بررسی‌های آغاز به کار
--------------------

QuisquisLingo پیش از اجرا، فایل‌های ضروری بسته، سازگاری Windows و Media
Foundation را بررسی می‌کند. این بررسی‌ها نرم‌افزاری را بارگیری یا نصب نمی‌کنند،
دسترسی بالاتر نمی‌خواهند، رجیستری را تغییر نمی‌دهند و Windows را دستکاری
نمی‌کنند.

در صورت وجود مشکل قابل عبور، یک پیام با گزینه‌های Continue anyway و Cancel
نمایش داده می‌شود. Continue anyway برای اجرای QQL تلاش می‌کند و Cancel آن را
می‌بندد. اگر فایل ضروری برنامه موجود نباشد، پیام گزینه Close را نشان می‌دهد،
زیرا بسته باید دوباره بارگیری و استخراج شود.

پشتیبانی Wine آزمایشی است. نبود Media Foundation در Wine ممکن است مانع اجرا یا
کارکرد ویژگی‌های صوتی و رسانه‌ای شود.

محیط اجرای MICROSOFT VISUAL C++
-------------------------------

بسته کامل شامل فایل‌های محیط اجرای Microsoft Visual C++ x64 زیر است:

msvcp140.dll
vcruntime140.dll
vcruntime140_1.dll

اگر یکی از آن‌ها موجود نیست، بسته کامل QuisquisLingo برای Windows را دوباره
بارگیری و به‌طور کامل استخراج کنید. برای نصب‌کننده‌های محیط اجرا فقط از منابع
رسمی Microsoft استفاده کنید و هیچ‌گاه فایل DLL جداگانه را از وب‌سایت‌های
متفرقه نگیرید.

اطلاعات رسمی Microsoft:
https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist

MEDIA FOUNDATION
----------------

نسخه‌های Windows N ممکن است برای امکانات صوتی و رسانه‌ای به Microsoft Media
Feature Pack نیاز داشته باشند. Media Feature Pack معمولاً در بخش Optional
Features در Windows در دسترس است. در برخی نسخه‌های Windows N ممکن است در آن
بخش موجود نباشد. در این صورت، Media Feature Pack مناسب نسخه Windows خود را از
وب‌سایت Microsoft بارگیری کنید.

پس از نصب Media Feature Pack، Windows را راه‌اندازی مجدد کنید. QuisquisLingo
آن را خودکار بارگیری یا نصب نمی‌کند و تنظیمات سیستم را تغییر نمی‌دهد.

تبدیل متن به گفتار
-----------------

QuisquisLingo از صداهای نصب‌شده در Windows استفاده می‌کند. زبان‌ها و صداهای
موجود به مؤلفه‌های زبان و صدای نصب‌شده در رایانه بستگی دارند. اگر صدای سازگاری
وجود ندارد، مؤلفه مناسب را از تنظیمات Windows نصب کنید.

Audio Settings > Test Voice فقط متنی را که وارد می‌کنید می‌خواند و از زبان
صدای تنظیم‌شده برای دوره انتخابی استفاده می‌کند.

گزارش‌ها و عیب‌یابی
------------------

گزارش اصلی خرابی در این مسیر ذخیره می‌شود:

Documents\QuisquisLingo\Logs\quisquislingo_crash.log

گزارش بررسی آغاز به کار در این مسیر ذخیره می‌شود:

%LOCALAPPDATA%\QuisquisLingo\Logs\quisquislingo_launcher.log

Settings > Debug گزینه‌های عیب‌یابی را نشان می‌دهد. گزارش‌ها روی رایانه محلی
می‌مانند و خودکار بارگذاری نمی‌شوند.

رفع اشکال
---------

1. کل بایگانی ZIP را به‌طور کامل استخراج کنید.
2. QuisquisLingo.exe را از بسته استخراج‌شده اجرا کنید.
3. اگر نبود یک DLL محیط اجرا گزارش شد، پیش از استفاده از نصب‌کننده رسمی
   Microsoft، بسته کامل را دوباره بارگیری و استخراج کنید.
4. اگر Media Feature Pack لازم است، راهنمای بالا را دنبال کنید و پس از نصب،
   Windows را راه‌اندازی مجدد کنید.
5. اگر QQL همچنان اجرا نمی‌شود، پیام خطای کامل و فایل‌های گزارش موجود را برای
   دریافت پشتیبانی نگه دارید.
